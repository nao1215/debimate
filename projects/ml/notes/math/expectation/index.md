期待値（expected value, `E[X]`）は、確率変数 `X` が取る値をその確率で重み付けして足し合わせた量です。離散の場合は `E[X] = Σ_x x P(x)`、連続の場合は確率密度 `f(x)` を使って `E[X] = ∫ x f(x) dx` と書きます。物理で言う質量分布の重心と同じ構造です。同じ分布から何度もサンプリングして平均を取ると、その平均は期待値に近づきます。

機械学習の[損失関数](/ml/ml/loss-functions/)の多くは、データ分布に対する期待値の形で定義されます。`R(θ) = E_{(x, y) ~ p}[ℓ(x, y, θ)]` を期待リスクと呼びます。真の分布 `p` は分からないので、訓練データの平均（経験リスク）で近似して最小化します。これが経験リスク最小化です。

<br>

本記事では、[NumPy](https://numpy.org/) と [SciPy](https://scipy.org/) で次の疑問を順に確かめます。

- 期待値と、手元のデータから計算する平均は何が違うのか
- サンプル数を増やすと、平均はどのくらいの速さで期待値に近づくのか
- 分布が歪むと、期待値・中央値・最頻値はどうずれるのか
- 相関がある変数でも、和や積の期待値を項ごとに分けられるのか

### 離散の期待値

サイコロを少し細工して、目が出る確率が下の表のように偏っているとします。

| 目 `x` | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| `P(X=x)` | 0.05 | 0.10 | 0.15 | 0.20 | 0.25 | 0.25 |

期待値は確率を重みとした和です。

`E[X] = 1×0.05 + 2×0.10 + 3×0.15 + 4×0.20 + 5×0.25 + 6×0.25 = 4.25`

以下は、この和を計算し、同じ確率でサイコロを 10 万回振った時の平均と比べる例です。本記事のコードは、上から順に 1 つのセッションで実行します。

```python
import numpy as np

xs = np.array([1, 2, 3, 4, 5, 6])
probs = np.array([0.05, 0.10, 0.15, 0.20, 0.25, 0.25])
print(f"E[X] = {(xs * probs).sum():.2f}")

rng = np.random.default_rng(0)
rolls = rng.choice(xs, size=100_000, p=probs)
print(f"10 万回振った平均 = {rolls.mean():.3f}")
```

出力:

```text
E[X] = 4.25
10 万回振った平均 = 4.247
```

{{< figure src="expectation_discrete.svg" alt="偏ったサイコロの 6 つの目の確率を青い棒で示し、赤い破線で E[X] = 4.25 の位置を引いた図。4.25 は棒の重心に当たり、サイコロの目には無い値" caption="偏ったサイコロの確率分布と期待値" align="center" >}}

赤い破線が `E[X] = 4.25` の位置で、青い棒（確率分布）の重心に当たります。4.25 という目はサイコロに無いように、期待値は取りうる値のひとつとは限りません。

期待値は[平均](../mean/)と混同しやすい概念ですが、両者は別物です。サンプル平均（標本平均, `x̄ = Σ x_i / n`）は手元のデータから計算する量で、上の 4.247 のように振るたびに変わります。期待値は確率分布から決まる量で、4.25 から動きません。

### 大数の法則: サンプル平均が期待値に近づく

独立に同じ分布から得たサンプル（独立同分布）で `E[|X|] < ∞` なら、サンプル数を増やすとサンプル平均は期待値 `E[X]` に収束します。これを[大数の法則](../lln-clt/)（law of large numbers）と呼びます。

公平なサイコロ（期待値 `(1+2+3+4+5+6)/6 = 3.5`、1 回の標準偏差 `σ = √(35/12) ≈ 1.708`）で、`n` 回振った平均を 1000 回ずつ作り、そのばらつきを測ります。

```python
sigma = np.sqrt(35 / 12)  # 公平なサイコロ 1 回の標準偏差
rng = np.random.default_rng(42)
for n in [10, 100, 1000]:
    means = rng.integers(1, 7, size=(1000, n)).mean(axis=1)
    print(f"n={n:4d}: 平均 {means.mean():.3f}, 標準偏差 {means.std():.3f}, σ/√n {sigma / np.sqrt(n):.3f}")
```

出力:

```text
n=  10: 平均 3.475, 標準偏差 0.533, σ/√n 0.540
n= 100: 平均 3.503, 標準偏差 0.170, σ/√n 0.171
n=1000: 平均 3.499, 標準偏差 0.052, σ/√n 0.054
```

{{< figure src="law_of_large_numbers.svg" alt="左は公平なサイコロを 1〜5000 回振った累積平均の 3 本の線で、どれも黒い破線の 3.5 に寄っていく。右は n = 10・100・1000 回の標本平均を 1000 個ずつ集めた分布で、n が大きいほど 3.5 の周りに狭く集まる" caption="累積平均と標本平均の分布" align="center" >}}

左の図は 3 回の試行で、サンプル数を 1 〜 5000 と増やした時の累積平均です。最初は大きく揺れますが、3 本とも黒い破線（期待値 3.5）に寄っていきます。右の図は `n` 回振った平均を 1000 個集めた分布で、`n` が増えるほど 3.5 の周りに集まります。

出力の標準偏差は 0.533 → 0.170 → 0.052 と、`n` を 10 倍にするたびに約 `1/√10` になり、`σ/√n` とほぼ一致します。精度を 1 桁上げるにはサンプルが 100 倍必要で、標準誤差や信頼区間の計算はこの関係を使います。

### 連続の期待値

連続変数の期待値は積分で定義されます。

`E[X] = ∫_{-∞}^{∞} x f(x) dx`

期待値が存在する対称な分布では、期待値は対称の中心、つまり中央値と一致します。山が 1 つなら最頻値も同じ位置です。代表的な分布の `E[X]` の公式は[代表的な確率分布](../probability-distributions/)のノートにまとめてあります。

非対称な分布では、この 3 つがずれます。以下は、正規分布と右に裾が長い[対数正規分布](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.lognorm.html)で、定義の積分と 3 つの代表値を比べる例です。

```python
from scipy import integrate, stats

norm = stats.norm(loc=3.0, scale=1.2)
logn = stats.lognorm(s=0.6, scale=np.exp(0.8))  # log X が平均 0.8、標準偏差 0.6 の正規分布
for name, d, mode in [("正規", norm, 3.0), ("対数正規", logn, np.exp(0.8 - 0.6**2))]:
    integral, _ = integrate.quad(lambda x: x * d.pdf(x), d.ppf(1e-12), d.ppf(1 - 1e-12))
    print(f"{name}: ∫x f(x)dx = {integral:.3f}, 期待値 {d.mean():.3f}, 中央値 {d.median():.3f}, 最頻値 {mode:.3f}")
```

出力:

```text
正規: ∫x f(x)dx = 3.000, 期待値 3.000, 中央値 3.000, 最頻値 3.000
対数正規: ∫x f(x)dx = 2.664, 期待値 2.664, 中央値 2.226, 最頻値 1.553
```

{{< figure src="expectation_continuous.svg" alt="左は正規分布で期待値・中央値・最頻値が 3.0 で重なる。右は対数正規分布で、最頻値 1.553・中央値 2.226・期待値 2.664 の順に右へずれる" caption="正規分布と対数正規分布の代表値" align="center" >}}

定義の積分を数値計算した値は、SciPy の `mean()` と一致しています。左の正規分布では `E[X]` がピーク（最頻値）と重なります。右の対数正規分布では、長い右の裾に引っ張られて、最頻値 1.553 < 中央値 2.226 < 期待値 2.664 の順に並びます。

期待値は、[中央値](../median/)のノートで見た平均と同じく外れ値の影響を強く受けます。ロバスト性が必要な時は、中央値やトリム平均（trimmed mean）を併用します。

### 期待値の重要な性質

期待値の使いやすさは、次の代数的性質に支えられています。

| 性質 | 式 | 条件 |
|---|---|---|
| 線形性 | `E[a X + b Y] = a E[X] + b E[Y]` | 常に成立（独立性は不要） |
| 定数 | `E[c] = c` | 常に成立 |
| 積 | `E[X Y] = E[X] E[Y] + Cov(X, Y)` | 常に成立 |
| 積の分解 | `E[X Y] = E[X] E[Y]` | `X, Y` が無相関（`Cov(X, Y) = 0`）の時。独立なら必ず成立 |

スカラー倍 `E[c X] = c E[X]` は、線形性で `b = 0` とした場合です。線形性は `X` と `Y` が独立でなくても成り立ち、共分散があっても和の期待値は期待値の和になります。一方で、積は共分散の分だけずれます。以下は、`Y` を `X` に依存させて作り、和と積の両方を確かめる例です。

```python
rng = np.random.default_rng(0)
n = 5000
X = rng.normal(2.0, 1.5, n)
Y = rng.chisquare(df=3, size=n) + 0.5 * X  # Y は X に依存する
print(f"相関係数 = {np.corrcoef(X, Y)[0, 1]:.3f}")
print(f"E[X+Y] = {(X + Y).mean():.3f}, E[X]+E[Y] = {X.mean() + Y.mean():.3f}")
print(f"E[XY] = {(X * Y).mean():.3f}, E[X]E[Y] = {X.mean() * Y.mean():.3f}")
print(f"Cov(X, Y) = {np.cov(X, Y, ddof=0)[0, 1]:.3f}")
```

出力:

```text
相関係数 = 0.291
E[X+Y] = 6.063, E[X]+E[Y] = 6.063
E[XY] = 9.235, E[X]E[Y] = 8.111
Cov(X, Y) = 1.123
```

{{< figure src="expectation_linearity.svg" alt="X、Y、X + Y のヒストグラム 3 枚。赤い破線はそれぞれの平均で、右端では X + Y の平均と E[X] + E[Y] がどちらも 6.06 で重なる" caption="相関があっても成り立つ期待値の線形性" align="center" >}}

3 つのヒストグラムは `X`、`Y`、`X + Y` のサンプル分布で、赤い破線がそれぞれの平均です。右図では `X + Y` の平均（赤）と、`X` と `Y` の平均の和（黒）が 6.06 で重なっています。相関係数 0.291 の相関があっても、和の期待値は分けられます。

積の方は 9.235 と 8.111 で一致せず、差は `Cov(X, Y) = 1.123`（理論値は `0.5 × Var(X) = 1.125`）です。

線形性のおかげで、複雑な確率モデルの期待値も項ごとに分解して足し算で扱えることが多いです。例えば、ニューラルネットの損失 `E[Σ_i ℓ_i]` は `Σ_i E[ℓ_i]` に分解でき、ミニバッチ平均も期待値の偏りのない推定になります。

### 条件付き期待値と全期待値の法則

ある変数 `X` の値を固定した時の、もう片方 `Y` の期待値を条件付き期待値（conditional expectation, `E[Y | X = x]`）と呼びます。「`x` が与えられた時の `y` の期待値」は、二乗誤差で学習する回帰モデルが近似する対象です。条件付き分布そのものは[同時分布・周辺分布・条件付き分布](../joint-marginal-conditional/)のノートで扱っています。

全期待値の法則（law of total expectation, tower property）を使うと、条件付き期待値から無条件の期待値を求められます。

`E[Y] = E[E[Y | X]]`

まず `X` を固定して条件付き期待値を計算し、それを `X` について平均すると、無条件の期待値になります。例えば、クラスごとの平均点をクラスの人数比で重み付けして平均すると、学年全体の平均点になります。階層的なデータ（クラスタ × サンプル）を扱う時や、ベイズ推論で事後期待値を求める時によく使います。

### 数学での使いどころ

- [分散](../variance/) の定義: `Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2`
- [相関](../correlation/) と共分散: `Cov(X, Y) = E[(X - E[X])(Y - E[Y])]`
- モーメント（`E[X^k]`）と特性関数（`E[exp(i t X)]`）
- 確率不等式: マルコフの不等式（`X ≥ 0`、`a > 0` の時 `P(X ≥ a) ≤ E[X] / a`）、チェビシェフの不等式
- イェンセンの不等式: 凸関数 `g` について `g(E[X]) ≤ E[g(X)]`
- [中心極限定理](../lln-clt/)（標本平均の分布が正規分布に近づく）

---

### 機械学習での使いどころ

- 損失関数の定義: 期待リスク `R(θ) = E_{(x, y)}[ℓ(x, y, θ)]` は訓練データの平均（経験リスク）で近似して最小化する
- バイアス: `Bias[ŷ] = E[ŷ] - y_true`（[バイアス-バリアンス分解](../../ml/bias-variance-tradeoff/) 参照）
- 回帰モデル: 二乗誤差で学習すると `ŷ(x) = E[Y | X = x]` を近似する
- [KL ダイバージェンス](../information-theory/): `KL(p || q) = E_p[log(p/q)]`
- 強化学習: 累積報酬の期待値 `V(s) = E[Σ_t γ^t r_t | s_0 = s]` の最大化
- 方策勾配・変分推論: 期待値の勾配を扱う（[REINFORCE](https://doi.org/10.1007/BF00992696)、ELBO）
- 確率モデルの周辺化: 潜在変数を持つモデルで `p(x) = E_z[p(x | z)]`
- ベイズ最適化: 獲得関数 [EI（Expected Improvement）](https://doi.org/10.1023/A:1008306431147)は「改善量の期待値」

### 適さないケース / 落とし穴

- 期待値が存在しないケース: 裾の重い分布（コーシー分布など）では `E[X]` が定義できない。サンプル平均は毎回計算できるが、`n` 個の平均も同じコーシー分布に従うため、何回増やしても収束しない
- 期待値が実用的な代表値にならないケース: 二峰性の強い分布では、期待値が「どちらの山にも属さない谷」を指すことがある（[平均](../mean/) のノート参照）
- サンプル平均は期待値の不偏推定量。一方で、分散の推定では `(1/n) Σ (x_i - x̄)^2` に偏りがあり、`(1/(n-1)) Σ (x_i - x̄)^2` の補正が必要になる
- 積の期待値の分解: `E[X Y] = E[X] E[Y]` は無相関の時だけ成り立つ。相関があれば `Cov(X, Y)` の分だけずれる
- 高次元での期待値計算の難しさ: 解析的に積分できないケースが大半で、モンテカルロ法（サンプル平均で近似）か変分近似が必要になる

確率分布（probability distribution）は、測るまで値が決まらない量が、どの値をどれくらいの確率で取るかを表したものです。サイコロの目や、1 時間に借りられた自転車の台数がその例で、こうした量を確率変数と呼びます。ML（機械学習）では、データにノイズを足す時、[損失関数](../../ml/loss-functions/)を選ぶ時、[ベイズの定理](../bayes-theorem/)で事前分布を置く時に、正規分布やポアソン分布といった名前で出てきます。

回数を数えたデータにはポアソン分布を当てはめる、と統計の入門で習います。ポアソン分布は平均を 1 つ決めると形が決まり、値のばらつきを表す[分散](../variance/)も平均と同じ値になる分布です。1 時間に借りられた自転車の台数も回数なので、ポアソン分布が当てはまりそうに見えます。

[Bike Sharing Dataset](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset) は、米国ワシントン D.C. の自転車シェアサービス Capital Bikeshare で、2011〜2012 年に 1 時間ごとに借りられた台数を記録した公開データです。

2012 年の平日 8 時で、天気が晴れだった 146 時間を取り出し、平均 625 台のポアソン分布を当てはめました。比べるために、平均に加えて分散も合わせられる負の二項分布も当てはめています。負の二項分布がどんな分布かは、後の節で説明します。

{{< figure src="pd_cover.webp" alt="横軸が 1 時間に借りられた台数、縦軸が時間の数のヒストグラム。灰色の実際の 146 時間は主に 400〜850 台に広く散らばり、400 台未満も 6 時間ある。赤いポアソン分布は 625 台を中心に細く尖り、95% の範囲は 577〜675 台で、入ったのは 36%。青い負の二項分布はなだらかな山で、95% の範囲は 393〜909 台、入ったのは 96%" caption="2012 年、平日 8 時（晴れ）に借りられた台数と、当てはめた 2 つの分布" align="center" >}}

図で下に引いた帯は、それぞれの分布で求めた 95% の範囲です。分布に従って値が出るなら 95% の値が入るはずの区間で、小さい側と大きい側から 2.5% ずつを除いて求めます。

ポアソン分布の 95% の範囲は 577〜675 台で、実際の 146 時間のうち、入ったのは 36% だけでした。分散は 17499 で平均の 28 倍あり、分散も合わせた負の二項分布なら、範囲は 393〜909 台に広がり、96% が入ります。

この差は、回数を予測するモデルで、予測した平均の周りに値が入りそうな範囲を計算する時に効いてきます。このような範囲を予測区間と呼びます。[scikit-learn](https://scikit-learn.org/stable/) には `loss="poisson"` を選べる回帰モデルがあります。このデータで 1 つのモデルを学習し、予測した平均からポアソン分布で 95% の予測区間を計算すると、ランダムに取り分けた評価用の時間で予測区間に入ったのは 64% だけでした。

本記事では、ML の説明に出てくる確率分布を自分で計算して確認したい人と、scikit-learn で回数のデータを予測する人に向けて、次の疑問に答えます。

- 確率と確率密度は何が違うのか。
- 二項分布・ポアソン分布・正規分布は、どうつながるのか。
- 回数のデータに、ポアソン分布はいつ当てはまるのか。
- 当てはまらない時は、どの分布を使うのか。
- 損失関数の選び方は、分布とどう関係するのか。

### 確率と確率密度

確率分布は、取る値が飛び飛びか続いているかで 2 種類に分かれます。表が出た回数のように 0, 1, 2, ... と数えられる値を取る分布を離散分布、身長のように連続した値を取る分布を連続分布と呼びます。

離散分布は、値ごとの確率を確率質量関数（probability mass function, PMF）で表します。連続分布では、ある 1 点ちょうどの値になる確率は 0 なので、代わりに確率密度関数（probability density function, PDF）を使い、範囲の面積で確率を表します。SciPy の [`scipy.stats`](https://docs.scipy.org/doc/scipy/reference/stats.html) で両方を計算しました。

```python
from scipy import stats
import numpy as np

binom = stats.binom(10, 0.3)                       # 10 回投げて、確率 0.3 の表が出る回数
print("二項分布の確率の合計:", round(binom.pmf(np.arange(11)).sum(), 6))
narrow = stats.norm(0, 0.1)                         # 平均 0、標準偏差 0.1 の正規分布
print("x = 0 の確率密度:", round(narrow.pdf(0), 3))
print("-0.1〜0.1 に入る確率:", round(narrow.cdf(0.1) - narrow.cdf(-0.1), 3))
print("x = 0 ちょうどになる確率:", narrow.cdf(0) - narrow.cdf(0))
```

```text
二項分布の確率の合計: 1.0
x = 0 の確率密度: 3.989
-0.1〜0.1 に入る確率: 0.683
x = 0 ちょうどになる確率: 0.0
```

{{< figure src="pd_pmf_pdf.webp" alt="左は 10 回投げて表の確率が 0.3 の二項分布の棒グラフで、3 回が 0.27 で最も高く、全ての棒の和が 1。右は平均 0 の正規分布で、標準偏差 0.1 の赤い曲線は x = 0 で高さ 3.99 まで上がり、-0.1〜0.1 の塗った面積が確率 0.683。標準偏差 1 の灰色の破線は高さ 0.4 ほどで平ら" caption="二項分布は棒の高さが確率、正規分布は面積が確率" align="center" >}}

左の二項分布は、棒の高さがそのまま確率で、11 本の和が 1 になります。右の正規分布は、x = 0 で高さが 3.99 あり、1 を超えています。確率密度は確率ではないので、1 を超えても問題ありません。確率は -0.1〜0.1 を塗った面積で、0.683 です。曲線より下を全て足した面積は 1 になります。灰色の破線は標準偏差 1 の正規分布で、幅が 10 倍広い分、高さは 0.4 ほどに下がります。

正規分布は、平均 `μ` を中心に左右対称の山になる連続分布で、ガウス分布とも呼びます。PDF は `f(x) = exp(-(x - μ)^2 / (2 σ^2)) / (σ √(2π))` で、`μ` で山の中心が、標準偏差 `σ` で山の幅が決まります。分散は `σ^2` なので、平均と分散を並べて `N(μ, σ^2)` と書きます。

コードの `cdf` は累積分布関数（cumulative distribution function, CDF）で、値が x 以下になる確率を返し、範囲の確率は CDF の差で求まります。平均 0、標準偏差 1 の正規分布 `N(0, 1)` を標準正規分布と呼び、その CDF は `Φ` と書くことが多く、[GELU](../../ml/activation-functions/) の定義にも出てきます。正規分布の平均 ± 1 標準偏差に約 68% が入ることは、[標準偏差](../stddev/)で説明しています。

### 二項分布からポアソン分布へ

二項分布は、確率 `p` で成功する試行を `n` 回独立に繰り返した時の、成功した回数の分布です。式は `P(X = k) = C(n, k) p^k (1 - p)^(n - k)` で、平均は `n p`、分散は `n p (1 - p)` です。1 回だけの試行（`n = 1`）はベルヌーイ分布と呼び、0 か 1 を取ります。

平均 `λ = n p` を保ったまま `n` を大きく、`p` を小さくすると、二項分布はポアソン分布 `P(X = k) = λ^k e^(-λ) / k!` に近づきます。起きる機会は多いが 1 回ごとにはめったに起きない事柄の回数が、ポアソン分布に従うということです。`(1 - p)` が 1 に近づくので、平均と分散はどちらも `λ` になります。

この例として有名なのが、Ladislaus von Bortkiewicz が 1898 年の[『Das Gesetz der kleinen Zahlen』](https://archive.org/details/dasgesetzderklei00bortrich)にまとめた、プロイセン陸軍で馬に蹴られて亡くなった兵士の数です。

R. A. Fisher は[『Statistical Methods for Research Workers』](http://psychclassics.yorku.ca/Fisher/Methods/chap3.htm)で、このうち 10 の軍団について 20 年分を取り上げています。合わせて 200 の「軍団・年」ごとに、1 年で亡くなった人数を数えたものです。

```python
deaths = np.array([0, 1, 2, 3, 4])                  # 1 軍団で 1 年に亡くなった人数
years = np.array([109, 65, 22, 3, 1])               # その人数だった軍団・年の数（計 200）
lam = (deaths * years).sum() / years.sum()
var_h = ((deaths - lam) ** 2 * years).sum() / (years.sum() - 1)
print(f"平均 {lam:.2f}、分散 {var_h:.2f}、分散 / 平均 {var_h / lam:.2f}")
expected = years.sum() * stats.poisson.pmf(deaths, lam)
print("ポアソン分布で予想した数:", expected.round(1))
binom_approx = years.sum() * stats.binom.pmf(deaths, 1000, lam / 1000)
print("1000 人がそれぞれ確率 0.00061 で亡くなる二項分布:", binom_approx.round(1))
```

```text
平均 0.61、分散 0.61、分散 / 平均 1.00
ポアソン分布で予想した数: [108.7  66.3  20.2   4.1   0.6]
1000 人がそれぞれ確率 0.00061 で亡くなる二項分布: [108.6  66.3  20.2   4.1   0.6]
```

{{< figure src="pd_horsekick.webp" alt="横軸が 1 軍団で 1 年に亡くなった人数の 0〜4 人、縦軸が軍団・年の数の棒グラフ。灰色の記録は 109、65、22、3、1、赤いポアソン分布の予想は 108.7、66.3、20.2、4.1、0.6 で、どの人数でも高さがほぼ揃う" caption="馬に蹴られて亡くなった兵士の数と、平均 0.61 のポアソン分布" align="center" >}}

記録とポアソン分布の予想は、どの人数でもほぼ一致し、分散は平均と同じ 0.61 です。1 軍団を 1000 人と置き、1 人ずつ確率 0.00061 で亡くなる二項分布で計算しても、予想は小数点以下 1 桁までほとんど変わりません。1 軍団に何人いたかを知らなくても、平均 1 つでポアソン分布が決まるのはこのためです。

ポアソン分布の `λ` が大きくなると、形は平均 `λ`、標準偏差 `√λ` の正規分布に近づきます。冒頭のポアソン分布が 625 台を中心に左右対称の細い山になったのはこのためで、標準偏差は `√625 = 25` 台しかありません。`n` の大きい二項分布も、平均 `n p`、分散 `n p (1 - p)` の正規分布に近づきます。ド・モアブル–ラプラスの定理と呼ばれる結果で、どちらも[中心極限定理](../lln-clt/)の例になっています。

### ポアソン分布から外れる回数

馬に蹴られた兵士の数と、借りられた自転車の台数は、どちらも回数です。違いを見るために、自転車のデータを「年・平日か休日か・時刻・天気」の組に分け、20 時間以上ある 222 組で平均と分散を計算しました。同じ組の中では、時刻や天気といった条件が揃っています。

データは、ML のデータを集めて公開している [OpenML](https://www.openml.org/d/42712) にある、同じデータを 1 時間単位にしたもので、`fetch_openml` が初回だけダウンロードします。`count` が 1 時間に借りられた台数です。

コードでは、組ごとの分散を「平均 + α × 平均の 2 乗」と置いた時の係数 `α` も求めています。`α` は平均の 2 乗に比例して増えるばらつきの大きさで、ポアソン分布なら 0 です。

```python
from sklearn.datasets import fetch_openml

bike = fetch_openml("Bike_Sharing_Demand", version=2, as_frame=True, parser="liac-arff").frame
groups = bike.groupby(["year", "workingday", "hour", "weather"], observed=True)["count"]
stat = groups.agg(["mean", "var", "size"])
stat = stat[stat["size"] >= 20]                     # 20 時間以上ある組だけ
alpha_g = np.median((stat["var"] - stat["mean"]) / stat["mean"] ** 2)
print(f"組の数 {len(stat)}、分散 / 平均 の中央値 {np.median(stat['var'] / stat['mean']):.1f}")
print(f"分散 = 平均 + α × 平均^2 の α（中央値）: {alpha_g:.3f}")
small = stat[stat["mean"] < 10]
print(f"平均 10 台未満の組 {len(small)} 個の 分散 / 平均 の中央値: {np.median(small['var'] / small['mean']):.1f}")
large = stat[stat["mean"] >= 100]
print(f"平均 100 台以上の組 {len(large)} 個の 分散 / 平均 の中央値: {np.median(large['var'] / large['mean']):.1f}")
```

```text
組の数 222、分散 / 平均 の中央値 27.7
分散 = 平均 + α × 平均^2 の α（中央値）: 0.192
平均 10 台未満の組 21 個の 分散 / 平均 の中央値: 2.8
平均 100 台以上の組 140 個の 分散 / 平均 の中央値: 40.2
```

{{< figure src="pd_meanvar.webp" alt="両対数の散布図。横軸が組の平均、縦軸が組の分散。青い自転車の 222 組は、平均 3 台ほどでは赤い「分散 = 平均」の線の近くにあるが、平均が大きくなるほど線から上に離れ、平均 300 台では分散が 3 千〜7 万になる。点は黒い破線の「分散 = 平均 + 0.192 × 平均²」に沿う。緑の星の馬に蹴られた兵士の数は、平均 0.61 で赤い線の上にある" caption="条件を揃えた組ごとの平均と分散" align="center" >}}

両軸とも対数の目盛りで、目盛り 1 つ分上がると値は 10 倍になります。ポアソン分布なら、点は赤い「分散 = 平均」の線に乗るはずです。平均が 10 台未満の組でも分散は平均の 2.8 倍あり、両対数の目盛りでは線の近くに見えるだけで、既にポアソン分布より広がっています。平均が大きい組ほど線から離れ、100 台以上の組では[中央値](../median/)で 40 倍になりました。このように分散が平均より大きくなる現象は、過分散（overdispersion）と呼ばれます。

点の並びは、`α` を 222 組の中央値 0.192 とした破線に沿っています。平均 300 台の組で赤い線より目盛り 1〜2 つ分上にあるのは、分散が平均の 10〜100 倍あるということです。

原因は、条件を揃えた組の中でも、日ごとに平均の台数が違うことだと考えられます。気温、風、行事、学校の休みで、同じ平日 8 時でも借りる人の数は変わります。日ごとの平均を `λ` とすると、まとめた台数の分散は `E[λ] + Var(λ)` で、ポアソン分布のばらつきに、`λ` そのもののばらつきが足されます。`E[λ]` は `λ` の[期待値](../expectation/)で、組の平均と同じです。`λ` が決まった上で台数が決まる、という条件付きの考え方は[同時分布・周辺分布・条件付き分布](../joint-marginal-conditional/)で説明しています。

冒頭の平日 8 時・晴れの組で、日ごとの `λ` をばらつかせてポアソン分布の乱数で台数を生成すると、どうなるかを描きました。日ごとの `λ` は、[ガンマ分布](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.gamma.html)の乱数で生成します。ガンマ分布は、正の値を取って右に裾を引く連続分布です。`λ` の平均は 625、`λ` の分散は冒頭の分散 17499 から平均 625 を引いた値にしています。

```python
rng = np.random.default_rng(0)
mu, var = 625.144, 17499.3                        # 冒頭の組の平均と分散（後のコードで計算した値）
shape = mu**2 / (var - mu)
gam = stats.gamma(shape, scale=mu / shape)        # 日ごとの平均 λ のばらつき（平均 mu、分散 var - mu）
lam_days = gam.rvs(size=200_000, random_state=rng)
counts = rng.poisson(lam_days)                    # 日ごとの λ でポアソン分布の乱数を生成
print(f"λ の平均 {lam_days.mean():.0f}、λ の分散 {lam_days.var():.0f}、"
      f"台数の分散 {counts.var():.0f}（E[λ] + Var(λ) = {lam_days.mean() + lam_days.var():.0f}）")
print("5 日の λ の例:", gam.ppf([0.1, 0.3, 0.5, 0.7, 0.9]).round(0))
```

```text
λ の平均 625、λ の分散 16917、台数の分散 17530（E[λ] + Var(λ) = 17542）
5 日の λ の例: [466. 551. 616. 686. 796.]
```

{{< figure src="pd_mixture.webp" alt="横軸が 1 時間に借りられた台数、縦軸が確率。灰色の細い山が 5 つあり、日ごとの平均 λ が 466、551、616、686、796 の日のポアソン分布を表す。どの山も幅は 100 台ほどしかない。青い線はたくさんの日を混ぜた分布で、5 つの山を包むように 300〜1000 台に広がる" caption="日ごとに平均が違うポアソン分布と、それを混ぜた分布" align="center" >}}

ある 1 日の台数は、灰色の細い山のどれかに従います。どの山も幅は冒頭の赤い山と同じくらい狭いのですが、山の位置が日によって 466 台から 796 台までずれます。たくさんの日をまとめると、青い線のように冒頭の実データと同じ広い山になります。灰色の山は 5 日のうちの 1 日分なので高さを 1/5 にしてあり、それでも青い線と同じくらいの高さがあるのは、幅が狭い分だけ確率が山の中央に集まるからです。

20 万日分を生成した台数の分散は 17530 で、`E[λ] + Var(λ)` の 17542 とほぼ一致しました。5 つの山は、`λ` のばらつきを小さい方から 10%、30%、50%、70%、90% の位置で切った値です。

借りる人の数が日ごとに 1 割、2 割と変わるなら、`λ` の標準偏差は平均に比例し、`Var(λ)` は平均の 2 乗に比例します。平均が小さい組では 1 項目の `E[λ]` が大きく、平均が大きい組では 2 項目の方が大きくなります。馬に蹴られた兵士の数は平均が 0.61 と小さく、`α` が自転車の中央値と同じ 0.19 あったとしても、分散は `0.19 × 0.61^2` で 0.07 しか増えません。緑の星が赤い線に乗ったのは、軍団や年ごとの違いがあっても分散に現れにくいほど平均が小さいからで、起きやすさが同じだったことの証拠にはなりません。

#### 負の二項分布

上の図のように、ポアソン分布の平均 `λ` がガンマ分布に従ってばらつく時、回数は負の二項分布に従います。負の二項分布は平均 `μ` と、ばらつきの大きさ `α` の 2 つで決まり、分散は `μ + α μ^2` です。散布図の破線がこの式で、`α = 0` ならポアソン分布に戻ります。

SciPy の [`nbinom`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.nbinom.html) は別の 2 つの値 `r` と `p` で指定するので、`r = 1 / α`、`p = r / (r + μ)` と置くと、平均 `μ`、分散 `μ + α μ^2` になります。

<br>

<details>
<summary>r と p の意味と、負の二項分布という名前</summary>

負の二項分布は元々、成功の確率が `p` の試行を繰り返し、`r` 回成功するまでに失敗した回数の分布です。確率の式に負の数を使った二項係数が現れることから、負の二項分布と呼ばれます。ガンマ分布で混ぜた形として使う時は、`r` は整数でなくても構いません。

</details>

<br>

冒頭の実験では、平日 8 時・晴れの 146 時間で平均と分散を計算し、両方が合うように `r` を決めました。比べるために、平均と分散を合わせた正規分布の範囲も計算しています。

```python
y = bike["count"].to_numpy()                      # 1 時間に借りられた台数
mask = ((bike["year"] == 1) & (bike["workingday"] == "True")
        & (bike["hour"] == 8) & (bike["weather"] == "clear")).to_numpy()
s = y[mask]                                       # 2012 年の平日 8 時、晴れの時間
mu, var = s.mean(), s.var(ddof=1)
print(f"時間の数 {len(s)}、平均 {mu:.1f} 台、分散 {var:.0f}、分散 / 平均 {var / mu:.1f}")

pois = stats.poisson(mu)                          # 平均だけで形が決まる
r = mu**2 / (var - mu)                            # 平均と分散が合うように負の二項分布の r を決める
nb = stats.nbinom(r, r / (r + mu))
norm = stats.norm(mu, np.sqrt(var))              # 比べるために、平均と分散を合わせた正規分布
for name, d in [("ポアソン分布", pois), ("負の二項分布", nb), ("正規分布", norm)]:
    lo, hi = d.ppf(0.025), d.ppf(0.975)           # 95% の範囲
    inside = np.mean((s >= lo) & (s <= hi))
    print(f"{name}: 95% の範囲 {lo:.0f}〜{hi:.0f} 台、入った時間 {inside:.0%}")
print(f"α = (分散 - 平均) / 平均^2 = {1 / r:.4f}、分散のうちポアソン分布の分 {mu / var:.1%}")
```

```text
時間の数 146、平均 625.1 台、分散 17499、分散 / 平均 28.0
ポアソン分布: 95% の範囲 577〜675 台、入った時間 36%
負の二項分布: 95% の範囲 393〜909 台、入った時間 96%
正規分布: 95% の範囲 366〜884 台、入った時間 96%
α = (分散 - 平均) / 平均^2 = 0.0432、分散のうちポアソン分布の分 3.6%
```

分散 17499 のうち、ポアソン分布で説明できるのは平均と同じ 625 の 3.6% だけで、残りは日ごとの平均のばらつきです。この組の `α` は 0.043 で、散布図で使った 222 組の中央値 0.19 より小さく、組ごとに `α` は違います。

平均が 625 台と大きいこの組では、平均と分散を合わせた正規分布でも 96% が入りました。台数が範囲に入るかを決めたのは、分布の名前より、分散を平均とは別に合わせたかどうかです。平均が数台の組では、正規分布は負の台数にも確率を割り当て、左右対称の形も合わないので、0 以上の整数だけを取る負の二項分布を使います。

同じことは二項分布でも起きます。`n` 回の試行で成功する確率 `p` が日や人ごとに違うと、成功した回数の分散は `n p (1 - p)` より大きくなります。この時は、0〜1 の値を取るベータ分布で `p` がばらつくとみなした、ベータ二項分布を使います。

### 損失関数と分布

ML で分布を選ぶ場面の多くは、損失関数を選ぶ場面です。観測したデータが出る確率を尤度と呼び、尤度が最大になるようにパラメータを決める方法を最尤推定と呼びます。平均二乗誤差（MSE）を最小にすることは、正解が予測の周りに分散が一定の正規分布でばらつくと仮定した最尤推定と同じです。同じように、[ロジスティック回帰](../../ml/logistic-regression/)の log loss はベルヌーイ分布、ポアソン逸脱度はポアソン分布の最尤推定に対応します。

scikit-learn の `loss="poisson"` が最小にするのはポアソン逸脱度の半分です。これは、ポアソン分布で求めた負の対数尤度から、予測に関係しない定数を除いた値です。半分にしても最小になる点は変わりません。

予測したい値の種類と、当てはめる分布の候補を並べます。ここまで出てこなかった指数分布とベータ分布は、次の節で説明します。

| 値の種類 | 分布 | 分散 | ML で出てくる所 |
|---|---|---|---|
| 0 か 1 | ベルヌーイ分布 | `p (1 - p)` | 分類の log loss |
| `n` 回中に成功した回数 | 二項分布 | `n p (1 - p)` | 正解率のばらつき |
| 上限の無い回数 | ポアソン分布 | 平均と同じ | `loss="poisson"` |
| 平均よりばらつく回数 | 負の二項分布 | `μ + α μ^2` | scikit-learn には無い |
| 次に起きるまでの時間 | 指数分布 | 平均の 2 乗 | 到着の間隔 |
| 正の実数（右に裾） | ガンマ分布 | 平均の 2 乗に比例 | `loss="gamma"` |
| 実数 | 正規分布 | 平均と別に決まる | MSE、ノイズ |
| 0〜1 の割合 | ベータ分布 | `平均 × (1 - 平均)` 未満 | 確率の事前分布 |

scikit-learn では、回帰の損失に `"poisson"` や `"gamma"` を選べるモデルのほか、[`PoissonRegressor`・`GammaRegressor`・`TweedieRegressor`](https://scikit-learn.org/stable/modules/linear_model.html#generalized-linear-models) が、分布を指定した線形モデルにあたります。[PyTorch](https://pytorch.org/) では、[`nn.GaussianNLLLoss`](https://docs.pytorch.org/docs/stable/generated/torch.nn.GaussianNLLLoss.html) や [`nn.PoissonNLLLoss`](https://docs.pytorch.org/docs/stable/generated/torch.nn.PoissonNLLLoss.html) が、正規分布やポアソン分布を仮定した負の対数尤度を損失として計算します。

<br>

#### 回数の予測区間

自転車のデータで、[HistGradientBoostingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.HistGradientBoostingRegressor.html) を 2 つの損失で学習しました。季節・時刻・天気・気温などの 12 列から、1 時間に借りられる台数を予測します。データは 6 割を学習、2 割を負の二項分布で使う `α` の推定、残りの 2 割を評価に分けました。時刻の順を考えずにランダムに分けたので、評価する 1 時間の前後にある時間が学習側に入っています。時刻で区切って未来を予測するより、範囲に入る割合は高めに出ている可能性があります。

```python
from scipy import optimize
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.model_selection import train_test_split

X = bike.drop(columns="count").copy()
for c in X.select_dtypes("category"):
    X[c] = X[c].cat.codes                           # 季節・天気などを整数の番号にする
X_tr, X_rest, y_tr, y_rest = train_test_split(X, y, test_size=0.4, random_state=0)
X_cal, X_te, y_cal, y_te = train_test_split(X_rest, y_rest, test_size=0.5, random_state=0)

sq = HistGradientBoostingRegressor(loss="squared_error", random_state=0).fit(X_tr, y_tr)
pred_sq = sq.predict(X_te)
print(f"squared_error: 負の予測 {np.sum(pred_sq < 0)} 件 / {len(y_te)} 件、最小 {pred_sq.min():.1f} 台")

po = HistGradientBoostingRegressor(loss="poisson", random_state=0).fit(X_tr, y_tr)
mu_cal, mu_te = po.predict(X_cal), po.predict(X_te)
print(f"poisson: 負の予測 {np.sum(mu_te < 0)} 件、予測の平均 {mu_te.mean():.1f} 台、実際の平均 {y_te.mean():.1f} 台")


def nb_nll(log_a):                                  # 評価用とは別の 2 割で α を最尤推定する
    rr = 1 / np.exp(log_a)
    return -stats.nbinom.logpmf(y_cal, rr, rr / (rr + mu_cal)).sum()


alpha = np.exp(optimize.minimize_scalar(nb_nll, bounds=(-10, 2), method="bounded").x)
rr = 1 / alpha
ranges = {"ポアソン分布": stats.poisson(mu_te), "負の二項分布": stats.nbinom(rr, rr / (rr + mu_te))}
print(f"負の二項分布の α: {alpha:.4f}")
inside = {}
for name, d in ranges.items():
    inside[name] = (y_te >= d.ppf(0.025)) & (y_te <= d.ppf(0.975))
    print(f"{name}: 予測した平均の周りの 95% の範囲に入った時間 {inside[name].mean():.0%}")
bins = [(0, 20), (20, 100), (100, 300), (300, 2000)]
for lo, hi in bins:
    k = (mu_te >= lo) & (mu_te < hi)
    print(f"予測 {lo}〜{hi} 台（{k.sum()} 時間）: "
          + "、".join(f"{n} {inside[n][k].mean():.0%}" for n in ranges))
```

```text
squared_error: 負の予測 63 件 / 3476 件、最小 -29.0 台
poisson: 負の予測 0 件、予測の平均 189.3 台、実際の平均 188.8 台
負の二項分布の α: 0.0543
ポアソン分布: 予測した平均の周りの 95% の範囲に入った時間 64%
負の二項分布: 予測した平均の周りの 95% の範囲に入った時間 93%
予測 0〜20 台（543 時間）: ポアソン分布 87%、負の二項分布 93%
予測 20〜100 台（825 時間）: ポアソン分布 66%、負の二項分布 88%
予測 100〜300 台（1338 時間）: ポアソン分布 57%、負の二項分布 93%
予測 300〜2000 台（770 時間）: ポアソン分布 59%、負の二項分布 98%
```

`loss="squared_error"` は、評価用の 3476 時間のうち 63 時間で負の台数を予測しました。正規分布は負の値にも確率を割り当てるので、この損失は予測が負になることを止めません。`loss="poisson"` は予測の対数をモデルで表すので負にならず、予測の平均 189.3 台は実際の 188.8 台とほぼ同じです。

{{< figure src="pd_model_cover.webp" alt="予測した平均で 4 つに分けた棒グラフ。赤いポアソン分布の 95% の範囲に入った割合は、20 台未満で 87%、20〜100 台で 66%、100〜300 台で 57%、300 台以上で 59%。青い負の二項分布は 93%、88%、93%、98% で、95% の破線の近くにある" caption="95% の範囲（予測区間）に、実際の台数が入った割合" align="center" >}}

ところが、予測した平均からポアソン分布で 95% の予測区間を計算すると、入ったのは 64% でした。予測した平均が 20 台未満の時間では 87% ですが、100 台以上では 57〜59% まで下がります。条件を揃えた組で見た傾向と同じで、特徴量で説明しきれない分のばらつきが、平均の 2 乗に比例して残っていると考えられます。予測した平均そのもののずれも範囲から外れる原因になりますが、ここでは 2 つを切り分けていません。

学習に使わなかった 2 割で、負の二項分布で使う `α` を推定すると 0.054 で、範囲に入った割合は 93% まで上がりました。ポアソン逸脱度で学習したモデルの平均はそのまま使い、予測区間の計算だけを負の二項分布で行っています。

<details>
<summary>過分散のデータでもポアソン逸脱度で学習してよいのか</summary>

平均を求める式の形を決めたモデルでは、その式が正しければ、分散が平均より大きくても、ポアソン分布の最尤推定で求めた平均はデータが増えるほど真の平均に近づきます。Gourieroux 氏らが 1984 年の[論文](https://doi.org/10.2307/1913472)で、疑似最尤推定（pseudo maximum likelihood）として示した性質です。勾配ブースティングのように式の形を決めないモデルには、この結果はそのまま当てはまりません。本記事の実験で分かるのは、評価用の時間で予測の平均 189.3 台が実際の 188.8 台とほぼ同じだったことまでです。

</details>

### 時間と割合の分布

回数の次によく出てくるのが、次に起きるまでの時間と、0〜1 の割合です。前者には指数分布、後者にはベータ分布を使います。どちらも連続分布です。

<br>

#### 指数分布

指数分布は、ポアソン分布に従って起きる事柄で、連続する 2 件の間隔や、待ち始めてから 1 件目までの時間の分布です。1 秒あたり平均 `λ` 件の要求がばらばらに届く時、届く件数はポアソン分布に従い、要求の間隔は PDF が `f(x) = λ e^(-λx)` の指数分布に従います。間隔の平均は `1 / λ` 秒、分散は `1 / λ^2` です。

この届き方をポアソン到着と呼び、[リトライとバックオフ](/notes/distributed-systems/retry-backoff/)でシミュレーションした要求もこの形で作っています。間隔を `k` 個足した `k` 件目までの時間は、ガンマ分布に従います。

指数分布には、既に何秒か待ったことが、残りの待ち時間の分布を変えない性質があります。この性質を無記憶性（memoryless property）と呼び、連続分布で無記憶性を持つのは指数分布だけです。コードでは、`λ = 2` の指数分布で計算しました。

```python
expo = stats.expon(scale=1 / 2)                     # 1 秒あたり平均 2 件届く時の、要求の間隔
print(f"指数分布: f(0) = {expo.pdf(0):.1f}、平均 {expo.mean():.2f} 秒、分散 {expo.var():.2f}")
print(f"1 秒待っても届かない確率: {expo.sf(1):.4f}")
print(f"3 秒待って届かなかった後、さらに 1 秒届かない確率: {expo.sf(4) / expo.sf(3):.4f}")
```

```text
指数分布: f(0) = 2.0、平均 0.50 秒、分散 0.25
1 秒待っても届かない確率: 0.1353
3 秒待って届かなかった後、さらに 1 秒届かない確率: 0.1353
```

`sf` は値が x より大きくなる確率で、`1 - cdf` と同じです。3 秒待って届かなかった後でも、さらに 1 秒届かない確率は、待ち始めた時と同じ 0.1353 でした。長く待ったから次はそろそろ届く、とはならないということです。

<br>

#### ベータ分布

ベータ分布は 0〜1 の値を取る分布で、PDF は `f(x) = x^(a-1) (1-x)^(b-1) / B(a, b)` です。`B(a, b)` は全体の面積を 1 にするための定数です。平均は `a / (a + b)` で、図の右のように、`a, b` の組み合わせで U 字・山型・左右に偏った形を作れます。表が出る確率のような、確率そのものの不確かさを表すのに使います。

冒頭で触れたベイズの定理では、コインの表が出る確率の事前分布にベータ分布を置き、表を `h` 回、裏を `t` 回見た後の分布が `Beta(a + h, b + t)` になります。どの確率も同じくらいありそうとみなす平らな `Beta(1, 1)` から始め、表 7 回・裏 3 回で更新しました。

```python
a, b, h, t = 1, 1, 7, 3                             # Beta(1, 1) から始めて、表 7 回・裏 3 回を見る
post = stats.beta(a + h, b + t)
lo, hi = post.ppf([0.025, 0.975])
print(f"事後分布 Beta({a + h}, {b + t}): 平均 {post.mean():.3f}、95% の範囲 {lo:.2f}〜{hi:.2f}")
```

```text
事後分布 Beta(8, 4): 平均 0.667、95% の範囲 0.39〜0.89
```

更新した `Beta(8, 4)` は、図の右で赤く描いた曲線です。平均 0.667 だけでなく、表が出る確率は 0.39〜0.89 のどこかにありそうだという幅まで表せます。

更新した後の分布が、更新する前と同じ形の分布になる組を共役と呼びます。ポアソン分布の `λ` とガンマ分布も共役の組です。日ごとの `λ` にガンマ分布を置いて混ぜた分布が、負の二項分布という式で書けたのもこの組み合わせのおかげです。分散が既知の正規分布で、平均の事前分布に正規分布を置く組も共役です。カテゴリが 3 つ以上ある時は、ベータ分布を広げたディリクレ分布（Dirichlet distribution）を使います。

A/B テストで案ごとのコンバージョン率の分布を求める時も、この更新を使います。候補ごとのクリック率の分布から乱数で値を 1 つずつ生成し、値が最大の広告を出す [Thompson sampling](https://doi.org/10.1093/biomet/25.3-4.285) も同じです。

<br>

<details>
<summary>正規分布が出てくる ML の場面</summary>

[拡散モデル](/notes/generative-ai/diffusion-model/)で画像に足すノイズや、[VAE](https://arxiv.org/abs/1312.6114)（Variational Autoencoder）の潜在変数は、正規分布に従います。

t 分布・χ² 分布・F 分布は、正規分布に従う値の平均や分散から作られ、[仮説検定](../hypothesis-test/)で使います。

scikit-learn の[ナイーブベイズ](https://scikit-learn.org/stable/modules/naive_bayes.html)にある GaussianNB は、クラスごとに特徴量へ正規分布を当てはめます。関数の値をまとめて多次元の正規分布に従うとみなすガウス過程は、ベイズ最適化で次に試す[ハイパーパラメータ](../../ml/hyperparameter/)を選ぶ時に使います。

</details>

<br>

### 分布を選ぶ前に見ること

最初に、予測したい値が取りうる範囲を見ます。0 か 1、上限のある回数、上限の無い回数、時間、正の実数、実数、0〜1 の割合のどれかで、表に並べた候補が絞れます。回数を MSE で学習すると負の予測が出ることがあります。MSE は正規分布を仮定した損失で、正規分布は負の値にも確率を割り当てるからです。正の実数で右に裾を引く値は、[歪度](../skewness/)を見て、ガンマ分布や log 変換を考えます。log を取ると正規分布に近づく値は、対数正規分布に従うとみなせます。

回数なら、次に条件を揃えた組で平均と分散を比べます。分散が平均とほぼ同じなら、馬に蹴られた兵士の数と同じくポアソン分布で足ります。平均の何倍もある過分散なら、負の二項分布を使います。平均が大きいほど差が開くので、平均が数台の組だけを見て決めないようにします。0 の時間だけが他より極端に多い時は、0 を別に扱うゼロ過剰ポアソン分布も候補になります。

次に裾の重さを見ます。正規分布なら、平均から 3 標準偏差より外れる値は 0.27% しかありません。外れ値の閾値を 3 標準偏差（3σ）で決めることが多いのはこのためですが、裾の重い分布では外れる値がずっと多くなります。分散を 1 に揃えた自由度 3 の t 分布と比べました。

```python
t3 = stats.t(3, scale=np.sqrt(1 / 3))               # 自由度 3 の t 分布を、分散が 1 になるように縮めたもの
for k in [2, 3, 4]:
    print(f"{k}σ の外: 正規分布 {2 * stats.norm.sf(k):.3%}、t 分布 {2 * t3.sf(k):.3%}")
```

```text
2σ の外: 正規分布 4.550%、t 分布 4.052%
3σ の外: 正規分布 0.270%、t 分布 1.385%
4σ の外: 正規分布 0.006%、t 分布 0.617%
```

分散が同じでも、3σ の外に出る値は t 分布で 5 倍、4σ の外では 100 倍ほどあります。対数正規分布やパレート分布のような裾の重いデータに正規分布の 3σ を当てはめると、外れ値の見積もりが楽観的になります。

ヒストグラムで山がいくつあるかも見ます。山が 2 つ以上ある時は、正規分布もポアソン分布も 1 つでは表せないので、山ごとの分布を混ぜた混合分布を当てはめます。scikit-learn では [Gaussian Mixture](https://scikit-learn.org/stable/modules/mixture.html) が、正規分布を混ぜたモデルです。

0〜1 の割合に 0 や 1 ちょうどの値が含まれる時は、ベータ分布をそのまま当てはめません。`a` や `b` が 1 以外だと端の確率密度が 0 か無限大になり、最尤推定が破綻するので、0 と 1 に別の確率を持たせた 0/1 過剰ベータ分布を使います。

ここまでの分布は、どれも値が互いに独立に出ると仮定しています。[時系列](../../ml/time-series-forecasting/)のように前の値が次の値に影響するデータでは、自己回帰モデルや HMM（隠れマルコフモデル）で、値のつながりも表します。

<br>

モデルで平均を予測するだけなら、`loss="poisson"` で学習した平均をそのまま使えます。予測区間を計算する、[異常検知](../../ml/anomaly-detection/)で多すぎる時間を見つける、置いておく台数の上限を決めるといった、ばらつきを使う所では、学習に使わなかったデータで `α` を推定し、予測区間に入る割合が 95% に近いかを見ます。データが時系列なら、評価用のデータは時刻で区切って取り分けます。

固有ベクトル（eigenvector）は、正方行列 `A` をかけても同じ直線の上にとどまるベクトルで、固有値（eigenvalue）はその時に長さが何倍になるかを表す数です。固有値分解は、行列を固有ベクトルと固有値の組に分けることです。[PCA](../../ml/pca/)（主成分分析）は、列の組ごとに一緒に増減する度合いを並べた共分散行列を固有値分解し、固有値の大きい順に並べた固有ベクトルを PC1、PC2 と呼ぶ主成分にします。

以下は、[scikit-learn](https://scikit-learn.org/stable/) に同梱の [wine](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_wine.html) を使った結果です。wine はワイン 178 本について化学分析の値を 13 列並べたデータで、各列を平均 0・分散 1 にそろえる[標準化](../../ml/standardization/)をしてから、共分散行列を固有値分解しました。さらに、同じ 178 本から重複を許して 178 本を選び直す操作を 200 回行い、そのたびに固有値分解して、主成分の向きが元の向きから何度ずれたかを測りました。この選び直しをブートストラップ（bootstrap）と呼びます。

{{< figure src="eig_cover.webp" alt="2 段の棒グラフ。上の段は wine の共分散行列の固有値で、PC1 から順に 4.73、2.51、1.45、0.92、0.86、0.65、0.55、0.35。PC4 と PC5 の 0.92 と 0.86 は赤。下の段は 200 回選び直した時の元の向きとの角度で、中央値は PC1 が 7 度、PC2 が 11 度、PC3 が 16 度、赤い PC4 が 43 度、PC5 が 50 度、PC6〜PC8 は 30〜35 度。90% 点の横線は PC4 と PC5 で 80 度を超える" caption="wine の固有値（上）と、行を選び直した時の固有ベクトルの角度（下）" align="center" >}}

PC1 の向きは、選び直しても中央値で 7 度しか動きません。一方で PC4 は中央値で 43 度、10 回に 1 回は 80 度以上ずれ、元の向きとほぼ直交します。PC4 と PC5 の固有値は 0.92 と 0.86 で、ほとんど差がありません。NumPy は毎回、エラーも警告も出さずに答えを返します。

主成分は元の 13 列に重みを掛けて足した列で、その重みが固有ベクトルの 13 個の成分です。重みの絶対値が一番大きい列から「PC4 は malic_acid の軸」と名前を付ける時や、固有値分解を NumPy で自分で書く時に、返り値をそのまま信じると困ります。NumPy には、他にもエラーを出さずに違う答えを返す場面があります。

<br>

本記事では、ML の説明に出てくる固有値分解を自分で計算して確かめたい人と、scikit-learn の PCA の結果を読む人に向けて、次の疑問に答えます。

- 固有ベクトルと固有値は、行列の何を表すのか。
- 対称行列の固有値分解は、変換をどう分けるのか。
- 固有値が近いと、なぜ固有ベクトルの向きが定まらないのか。
- `eig` と `eigh` を取り違えると、何が返るのか。
- scikit-learn の PCA で、小さい分散が 0 になるのはなぜか。

実験は [NumPy](https://numpy.org/) 2.5.4 と scikit-learn 1.9.1 で行いました。図を描く処理も含めた完全なコードは [eigen-decomposition_gen.py](https://github.com/nao1215/debimate/blob/main/projects/ml/scripts/notes/eigen-decomposition_gen.py) にあります。

### 固有ベクトルと固有値

固有ベクトルと固有値を式で書くと、`A v = λ v` を満たす `v ≠ 0` と `λ` です。一般のベクトルは `A` をかけると向きも長さも変わりますが、固有ベクトルは `λ` 倍されるだけです。`λ > 0` なら向きはそのまま、`λ < 0` なら真逆を向き、`λ = 0` ならその方向は潰れます。

行列 `A = [[2, 1], [0, 3]]` を例に取り、[`np.linalg.eig`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eig.html) で固有値と固有ベクトルを求めて `A v` と比べます。

```python
A = np.array([[2.0, 1.0], [0.0, 3.0]])
eigvals, eigvecs = np.linalg.eig(A)
for lam, v in zip(eigvals.real, eigvecs.real.T):
    print(f"λ={lam:.1f}  v={np.round(v, 3)}  Av={np.round(A @ v, 3)}")
```

```text
λ=2.0  v=[1. 0.]  Av=[2. 0.]
λ=3.0  v=[0.707 0.707]  Av=[2.121 2.121]
```

`eig` は、虚部が 0 でも複素数の配列で返すことがあるので、`.real` で実部を取っています。次の図は、長さ 1 のベクトル 18 本に `A` をかけた結果です。

{{< figure src="eig_action.webp" alt="左は長さ 1 のベクトル 18 本を上半分に扇形に並べた図で、赤い固有ベクトル (1, 0) と (0.707, 0.707) を重ねている。右は A をかけた後で、青いベクトルの多くは向きが変わり、赤い 2 本だけが同じ向きのまま λ=2 と λ=3 の倍数だけ伸びる" caption="A をかける前後のベクトル" align="center" >}}

青いベクトルの多くは向きが変わり、赤い固有ベクトルだけが同じ向きのまま 2 倍・3 倍に伸びます。行列とベクトルの積を線形変換として見る考え方は、[ベクトルと行列の演算](../vector-matrix-ops/)で説明しています。

### 対称行列の固有値分解

`n × n` の行列が `n` 本の線形独立な固有ベクトルを持つ時、`A = Q Λ Q^-1` と分解できます。`Q` は固有ベクトルを列に並べた行列、`Λ` は固有値を対角に並べた行列で、この形に分解することを対角化と呼びます。

`A` が対称行列なら、固有値は全て実数で、固有ベクトルは互いに直交するように選べます。`Q` の逆行列は転置になり、`A = Q Λ Q^T` と書けます。共分散行列は対称なので、PCA はこの形です。対称行列向けの [`np.linalg.eigh`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html) で分解し、戻すと `A` に一致するかを確かめます。

```python
A = np.array([[3.0, 1.0], [1.0, 2.0]])  # 対称行列
eigvals, Q = np.linalg.eigh(A)          # 固有値の昇順で返る
eigvals, Q = eigvals[::-1], Q[:, ::-1]  # 大きい順に並べ替える
Lam = np.diag(eigvals)

print("λ =", np.round(eigvals, 3))
print("Q =", np.round(Q, 3).tolist())
print("q1・q2 =", round(float(Q[:, 0] @ Q[:, 1]), 3))
print("Q Λ Q^T == A:", np.allclose(Q @ Lam @ Q.T, A))
```

```text
λ = [3.618 1.382]
Q = [[-0.851, 0.526], [-0.526, -0.851]]
q1・q2 = -0.0
Q Λ Q^T == A: True
```

上記の `Q` の 1 列目は 2 つの成分が両方とも負ですが、固有ベクトルは符号を反転しても固有ベクトルなので、`eigh` が返す向きの符号に意味はありません。次の図は、`q1` が右上を向くように 2 列とも符号を反転して描きました。2 列とも反転しても、`Q` は回転のままです。後で示す wine の実験でも、同じ理由で符号を無視して角度を測ります。

`Q` は回転なので、`A` の作用は「`Q^T` で回して固有ベクトルを座標軸に合わせる → 軸ごとに固有値倍に伸ばす → `Q` で戻す」の 3 段に分けられます。

{{< figure src="eig_steps.webp" alt="4 枚の図。1 枚目は単位円と赤の q1・緑の q2。2 枚目は Q^T で回して q1 が横軸、q2 が縦軸に乗る。3 枚目は横に 3.62 倍、縦に 1.38 倍に伸ばして楕円になる。4 枚目は Q で戻して、楕円が右上に傾く" caption="対称行列の固有値分解は、回す・伸ばす・戻すの 3 段" align="center" >}}

4 枚目の楕円は、単位円に `A` を直接かけた形と一致します。楕円の長い軸の向きが最大の固有値の固有ベクトルで、PCA の PC1 はこの向きです。共分散行列で同じ図を描き、固有値が各主成分の分散になることは、[PCA のノート](../../ml/pca/)の最初の節で確かめています。

同じ分解は PCA 以外にも使われます。損失をモデルのパラメータで 2 回微分した行列を固有値分解すると、固有値が向きごとの曲率になり、[勾配降下法](../gradient-descent-sgd/)の学習率の上限を決めます。[スペクトラルクラスタリング](https://proceedings.neurips.cc/paper/2001/hash/801272ee79cfde7fa5960571fee36b9b-Abstract.html)はデータのつながりを表す行列の、[カーネル PCA](https://doi.org/10.1162/089976698300017467) はカーネル行列の固有ベクトルを使います。

### 固有値が近い時の固有ベクトル

冒頭の PC4 が大きく動いた理由は、2 つの固有値の差にあります。2 × 2 の対角行列 `diag(1 + 差, 1)` は、固有ベクトルが `(1, 0)` と `(0, 1)` です。この行列に、標準偏差 0.01 の乱数で作った小さな対称行列を足し、大きい方の固有値の固有ベクトルがどこを向くかを 100 回調べました。

```python
rng = np.random.default_rng(0)
for gap in [1.0, 0.1, 0.01]:
    A = np.diag([1.0 + gap, 1.0])  # 固有ベクトルは (1, 0) と (0, 1)
    v1s = []
    for _ in range(100):
        E = rng.normal(scale=0.01, size=(2, 2))
        E = (E + E.T) / 2                    # 大きさ 0.01 ほどの対称な揺れ
        _, V = np.linalg.eigh(A + E)
        v1s.append(V[:, 1])                  # 大きい方の固有値の固有ベクトル
    v1s = np.array(v1s)
    deg = np.degrees(np.arccos(np.abs(v1s[:, 0])))  # (1, 0) からの角度。符号は任意なので絶対値
    print(f"固有値の差 {gap:<5}: 角度の中央値 {np.median(deg):5.1f} 度、最大 {deg.max():5.1f} 度")
```

```text
固有値の差 1.0  : 角度の中央値   0.3 度、最大   1.2 度
固有値の差 0.1  : 角度の中央値   2.9 度、最大  12.2 度
固有値の差 0.01 : 角度の中央値  27.5 度、最大  84.4 度
```

{{< figure src="eig_gap.webp" alt="3 枚の図に、100 回分の固有ベクトルを原点を通る赤い線で重ねている。固有値の差が 1 の左は全ての線が横の点線に重なる。差 0.1 の中央は横向きの細い扇形に広がる。差 0.01 の右は線があらゆる向きに散らばり、円を埋める" caption="同じ大きさの揺れでも、固有値の差が小さいと固有ベクトルは大きく回る" align="center" >}}

揺れの大きさは 3 つとも同じです。固有値の差が 1 なら固有ベクトルはほぼ動かず、差が 0.01 で揺れと同じくらいになると、100 回の向きが円を埋めるほど散らばり、最大で 84 度ずれました。固有値が等しい極端な場合は、2 本の固有ベクトルが張る平面の中のどの向きも固有ベクトルなので、向きは 1 つに決まりません。

固有ベクトルが傾く角度は、おおよそ「揺れの大きさ ÷ 固有値の差」で上から抑えられることが、Davis 氏と Kahan 氏の [1970 年の論文](https://doi.org/10.1137/0707001)で示されています。差が小さいほど、同じ揺れで大きく回れるということです。

#### 選び直しは、共分散行列への小さな揺れ

データの行を選び直すと、共分散行列は少しだけ変わります。冒頭の実験は、この揺れを wine の共分散行列に加えたのと同じです。次のコードは、角度に加えて、揺れの大きさと、選び直した PC4 で重みの絶対値が一番大きい列も数えます。

```python
wine = load_wine()
X = StandardScaler().fit_transform(wine.data)          # 178 行 × 13 列を標準化
C = np.cov(X, rowvar=False)
lam, V = np.linalg.eigh(C)
lam, V = lam[::-1], V[:, ::-1]                         # 固有値の大きい順
names = np.array(wine.feature_names)
print("元の PC4 で重みの絶対値が最大の列:", names[np.argmax(np.abs(V[:, 3]))])
K = 8
rng = np.random.default_rng(0)
ang = np.zeros((200, K))
swap = 0
shake = []                                             # 共分散行列の揺れの大きさ
top4 = []                                              # 選び直した PC4 で重みが最大の列
for b in range(200):
    Xb = X[rng.integers(0, len(X), len(X))]            # 重複を許して 178 行を選び直す
    Cb = np.cov(Xb, rowvar=False)
    _, Vb = np.linalg.eigh(Cb)
    Vb = Vb[:, ::-1]
    cos = np.abs(np.sum(V[:, :K] * Vb[:, :K], axis=0))  # 符号は任意なので絶対値
    ang[b] = np.degrees(np.arccos(np.clip(cos, 0, 1)))
    swap += abs(V[:, 4] @ Vb[:, 3]) > abs(V[:, 3] @ Vb[:, 3])  # 選び直した PC4 が元の PC5 に近い
    shake.append(np.linalg.norm(Cb - C, 2))            # 揺れの行列の 2 ノルム
    top4.append(names[np.argmax(np.abs(Vb[:, 3]))])
print("固有値:", lam[:K].round(3))
print("角度の中央値:", np.median(ang, axis=0).round(1))
print("角度の 90% 点:", np.percentile(ang, 90, axis=0).round(1))
print(f"選び直した PC4 が、元の PC4 より元の PC5 に近かった回数: {swap} / 200")
print(f"共分散行列の揺れの大きさ（中央値）: {np.median(shake):.2f}")
col, cnt = np.unique(top4, return_counts=True)
print("選び直した PC4 で重みが最大の列:", dict(sorted(zip(col.tolist(), cnt.tolist()), key=lambda t: -t[1])[:3]))
```

```text
元の PC4 で重みの絶対値が最大の列: malic_acid
固有値: [4.732 2.511 1.454 0.924 0.858 0.645 0.554 0.35 ]
角度の中央値: [ 6.6 11.4 16.  43.2 49.7 34.7 35.1 29.8]
角度の 90% 点: [11.6 18.7 30.9 80.5 81.7 71.4 64.1 56.8]
選び直した PC4 が、元の PC4 より元の PC5 に近かった回数: 81 / 200
共分散行列の揺れの大きさ（中央値）: 0.63
選び直した PC4 で重みが最大の列: {'magnesium': 80, 'malic_acid': 59, 'proanthocyanins': 22}
```

揺れの大きさは、揺れの行列が長さ 1 のベクトルを最大で何倍に伸ばすかを表す 2 ノルムで測り、中央値は 0.63 でした。

PC1 は次の PC2 と固有値が 2 以上離れていて、揺れより差が大きいので、7 度ほどしか動きません。PC4 と PC5 は差が 0.07 しかなく、揺れの方が 9 倍ほど大きいので、選び直すたびに 2 本の順番が入れ替わったり、2 本が張る平面の中で回ったりします。PC6〜PC8 も隣との差が 0.06〜0.21 しかなく、中央値で 30〜35 度動きます。

元の PC4 で重みの絶対値が一番大きい列は malic_acid でした。ところが選び直した 200 回のうち、PC4 で一番大きい列が malic_acid だったのは 59 回で、magnesium の 80 回より少なくなりました。magnesium は元の PC5 で重みが一番大きい列なので、PC4 と PC5 の入れ替わりがそのまま名前の入れ替わりになっています。

### eig と eigh の取り違え

NumPy には、どんな正方行列にも使える `eig` と、対称行列専用の `eigh` があります。`eigh` は速く、固有値を実数の昇順で返し、固有ベクトルが直交することも保証されるので、共分散行列には `eigh` を使います。ただし、`eigh` は渡された行列が対称かどうかを確かめません。[文書](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)の `UPLO` の説明のとおり、既定では下三角の部分だけを読み、上三角は対称だとみなして捨てます。

対称ではない行列の代表は、マルコフ連鎖の遷移行列です。マルコフ連鎖は、次の状態が今の状態だけで決まる確率のモデルで、遷移行列の `i` 行 `j` 列に「今日が `i` なら明日が `j` になる確率」を並べます。長い目で見た各状態の割合を定常分布と呼び、遷移行列の転置の、固有値 1 の固有ベクトルとして求まります。Web ページの重要度を測る [PageRank](http://infolab.stanford.edu/~backrub/google.html) も、同じ計算です。晴・曇・雨の 3 つの天気で、`eig` と `eigh` を比べました。

```python
P = np.array([[0.9, 0.1, 0.0],   # 晴 → 晴・曇・雨
              [0.2, 0.7, 0.1],   # 曇 → 晴・曇・雨
              [0.1, 0.3, 0.6]])  # 雨 → 晴・曇・雨

lam_e, V_e = np.linalg.eig(P.T)
pi_eig = V_e[:, np.argmax(lam_e.real)].real
pi_eig /= pi_eig.sum()

lam_l, V_l = np.linalg.eigh(P.T)               # 対称ではない行列を渡す（既定は下三角）
pi_l = V_l[:, -1] / V_l[:, -1].sum()
lam_u, V_u = np.linalg.eigh(P.T, UPLO="U")     # 上三角を使わせる
pi_u = V_u[:, -1] / V_u[:, -1].sum()

x = np.full(3, 1 / 3)
for _ in range(1000):                          # 実際に 1000 日分の遷移を掛ける
    x = x @ P

print("eig            : 最大の固有値", round(float(lam_e.real.max()), 4), "分布", pi_eig.round(4))
print("eigh（下三角）  : 最大の固有値", round(float(lam_l[-1]), 4), "分布", pi_l.round(4))
print("eigh（上三角）  : 最大の固有値", round(float(lam_u[-1]), 4), "分布", pi_u.round(4))
print("1000 日後       :", x.round(4))
```

```text
eig            : 最大の固有値 1.0 分布 [0.6429 0.2857 0.0714]
eigh（下三角）  : 最大の固有値 0.9461 分布 [0.6275 0.289  0.0835]
eigh（上三角）  : 最大の固有値 1.1475 分布 [0.3883 0.3494 0.2623]
1000 日後       : [0.6429 0.2857 0.0714]
```

{{< figure src="eig_markov.webp" alt="晴・曇・雨ごとに 4 本の棒を並べた図。1000 日分の遷移を掛けた結果と eig は 0.64、0.29、0.07 で一致する。既定の eigh は 0.63、0.29、0.08 で僅かにずれ、UPLO を U にした eigh は 0.39、0.35、0.26 と大きくずれる" caption="eig と 2 通りの eigh で求めた、天気の遷移行列の定常分布" align="center" >}}

`eig` の答えは、1000 日分の遷移を実際に掛けた結果と一致しました。既定の `eigh` は 0.63・0.29・0.08 と、それらしい値を返します。最大の固有値は 0.946 で、固有値 1 がありません。

遷移行列は各行の和が 1 なので、全ての成分が 1 のベクトルにかけると同じベクトルが返り、必ず固有値 1 を持ちます。転置しても固有値は変わりません。

読む三角を上に変えると、最大の固有値は確率の行列ではありえない 1.148 になり、分布も大きく変わります。既定でも上三角でも、エラーは出ません。`eigh` に渡す前に `np.allclose(A, A.T)` で対称かを確かめます。

#### 対角化できない行列で eig が返すもの

`eig` にも、固有値が近い時の落とし穴があります。対称ではない行列では、2 つの固有値が近づくと、2 本の固有ベクトルが回るのではなく、同じ向きに寄っていきます。

`[[1, 1], [0, 1 + ε]]` の固有値は 1 と `1 + ε` で、`ε` を 0 に近づけて `eig` を呼び、2 本の固有ベクトルの角度と、固有ベクトルを並べた `V` の条件数 cond(V) を出しました。条件数は、`V` の逆行列を使う計算で誤差が何倍に増えうるかの目安で、2 本が平行に近いほど大きくなります。

```python
for eps in [1.0, 1e-1, 1e-2, 1e-4, 1e-8, 0.0]:
    J = np.array([[1.0, 1.0], [0.0, 1.0 + eps]])  # 固有値は 1 と 1 + eps
    w, V = np.linalg.eig(J)
    w, V = w.real, V.real
    deg = np.degrees(np.arctan2(abs(V[0, 0] * V[1, 1] - V[1, 0] * V[0, 1]), abs(V[:, 0] @ V[:, 1])))
    print(f"eps={eps:<6g} 固有値 {np.round(w, 8)}  2 本の角度 {deg:9.2e} 度  cond(V) {np.linalg.cond(V):.1e}")
```

eps=0.1    固有値 [1.  1.1]  2 本の角度  5.71e+00 度  cond(V) 2.0e+01
eps=0.01   固有値 [1.   1.01]  2 本の角度  5.73e-01 度  cond(V) 2.0e+02

`ε` が 0.1 より小さい範囲では、`ε` が 10 分の 1 になるごとに角度は 10 分の 1、条件数は 10 倍になります。`ε = 0` の `[[1, 1], [0, 1]]` は、固有ベクトルが `(1, 0)` 方向の 1 本しかなく、`Q Λ Q^-1` の形に分解できない、つまり対角化できない行列です。

それでも `eig` は 2 本の列を返し、2 本の角度は 1e-14 度、条件数は 9.0e+15 でした。この `V` で `V Λ V^-1` を組み立て直しても、元の行列は信用できる精度では戻りません。

### 小さい分散が 0 になる PCA

共分散行列を作らずに、各列から平均を引いて中心化したデータ `X` を直接[特異値分解](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)（SVD、Singular Value Decomposition）しても、同じ主成分が求まります。SVD は、長方形の行列にも使える分解 `X = U Σ V^T` で、`V` の列が共分散行列の固有ベクトル、特異値 `Σ` の 2 乗を `n - 1` で割った値が固有値になります。

2 つは数学の上では同じですが、数値の上では違います。float64 では、1 の次に表せる数が 1 + 約 2.2e-16 で、これより細かい差は丸められて区別できません。共分散行列は `X^T X` を含み、固有値は特異値の 2 乗なので、値の範囲が 2 乗に広がります。一番大きい固有値の 1e-16 倍ほどより小さい固有値は丸めの幅に埋もれ、特異値で言えばその平方根の 1e-8 倍ほどより小さい成分が消えます。

scikit-learn 1.9.1 の [`PCA`](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html) では、`svd_solver` の既定の `"auto"` は、列が 1000 以下で、行が列の 10 倍以上なら、共分散行列を固有値分解する `"covariance_eigh"` を選びます。この solver は 1.5 で入ったもので、文書にも `"full"` より数値的に不安定だと書かれています。

主成分の分散が 1、1、`s²` になるデータを作り、`PCA` が返す一番小さい分散を比べました。

```python
rng = np.random.default_rng(0)
n = 1000
G = rng.normal(size=(n, 3))
G -= G.mean(axis=0)
U, _ = np.linalg.qr(G)                          # 平均 0 で、互いに直交する長さ 1 の 3 列
R, _ = np.linalg.qr(rng.normal(size=(3, 3)))    # 主成分の向きを列の軸からずらす回転
ss = 10.0 ** -np.arange(1, 12)
err = {"auto": [], "covariance_eigh": [], "full": []}
for s in ss:
    X = np.sqrt(n - 1) * U @ np.diag([1.0, 1.0, s]) @ R  # 主成分の分散は 1、1、s^2
    for solver in err:
        v = PCA(svd_solver=solver).fit(X).explained_variance_[-1]
        err[solver].append(abs(v - s**2) / s**2)
        if s in (1e-4, 1e-8, 1e-10):
            print(f"s={s:.0e} 正しい分散 {s**2:.1e}  {solver:<15} {v:.3e}")
```

`"auto"` と `"covariance_eigh"` の出力は全ての `s` で一致したので、出力は `"auto"` だけを載せています。1000 行 × 3 列のこのデータでは `"auto"` が `"covariance_eigh"` を選び、`s = 1e-8` で分散を 0 と返しました。`s = 1e-10` では、正しい値の 8000 倍の 8.3e-17 を返しています。`"full"` は SVD を使い、どちらも正しく返しました。

大きい主成分を使うだけなら、この差は問題になりません。主成分の値を分散の平方根で割って大きさをそろえる白色化（`whiten=True`）や、分散がほぼ 0 の主成分で列の間の重複を探す時は、`svd_solver="full"` を指定します。[線形回帰](../../ml/linear-regression/)の係数を `X^T X` の逆行列で求めず、SVD を使う関数で解くのも同じ理由です。

### 固有ベクトルを読む前に確かめること

PCA の主成分に名前を付ける前に、固有値を大きい順に並べ、隣との差を見ます。冒頭の図の PC4 と PC5 のように差が小さければ、行を選び直して固有値分解を繰り返し、向きがどれだけ動くかを測ります。PC1 のように隣と離れた主成分なら、選び直しても向きはほぼ保たれます。

動くなら、その 2 本には列の名前を付けず、説明には向きの安定した主成分を使います。wine では PC4 で一番重い列が、選び直すたびに malic_acid と magnesium の間で入れ替わりました。何本の主成分を残すかを決める時も、PC4 と PC5 のように固有値の近い 2 本の間で切らず、残すなら 2 本とも残します。片方だけ残すと、残した 1 本がデータ次第でもう片方の向きになるからです。

固有値分解を自分で書く時は、行列が対称かを先に `np.allclose(A, A.T)` で確かめます。対称なら `eigh` で、遷移行列のように対称でなければ `eig` で分解し、`eig` の返した `V` の条件数が大きければ、`V` の逆行列を使う計算を避けます。どちらの関数も、前提が崩れてもエラーは出しません。

最後に、小さい分散を使うかを考えます。PCA で上位の主成分だけを残すなら scikit-learn の既定のままでよく、分散がほぼ 0 の主成分を見たり、分散で割ったりするなら `svd_solver="full"` にします。冒頭の図の上の段で、どこに固有値の近い組があり、どこに 0 に近い固有値があるかを見ることが、両方の出発点になります。

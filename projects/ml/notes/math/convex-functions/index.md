凸関数（convex function）は、グラフの上のどの 2 点を線分で結んでも、その線分がグラフより下に来ない関数です。[線形回帰](../../ml/linear-regression/)や[ロジスティック回帰](../../ml/logistic-regression/)の損失は、係数について凸関数なので、学習率が大きすぎず最小の点があれば、勾配の逆向きに下っていって一番低い所に着きます。

ただし、凸関数を最小にする問題なら、どの solver・どの seed で解いても同じ係数が返る、とは限りません。solver は最小の点を探す計算の手順のことです。凸関数が保証するのは、止まった所が一番低い値であることで、その値を出す係数の組は 1 つとは限らないからです。

<br>

[scikit-learn](https://scikit-learn.org/stable/) に同梱の [diabetes](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_diabetes.html) は、糖尿病の患者 442 人について、年齢・BMI・血圧など 10 列と、1 年後に病気がどれだけ進んだかを並べたデータです。ここに、bmi を 10 倍して 3 を足した列 bmi_copy を足しました。同じ量を別の単位で記録した列が混ざった状態です。各列を平均 0・[標準偏差](../stddev/) 1 にそろえる[標準化](../../ml/standardization/)をすると、2 列は全く同じ値になります。

```python
d = load_diabetes(as_frame=True)
X = d.data.copy()
y = d.target.to_numpy()
X["bmi_copy"] = X["bmi"] * 10 + 3          # 同じ量を別の単位で記録した列
Xs = StandardScaler().fit_transform(X)     # 標準化すると bmi と bmi_copy は同じ値になる
n = len(y)
i_bmi, i_copy = X.columns.get_loc("bmi"), X.columns.get_loc("bmi_copy")
print("bmi と bmi_copy の差の最大:", np.abs(Xs[:, i_bmi] - Xs[:, i_copy]).max())
```

```text
bmi と bmi_copy の差の最大: 1.3322676295501878e-15
```

この 11 列に [Lasso](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html) を当てはめました。Lasso は、予測と正解の差を 2 乗した損失に、係数ごとの絶対値を足し合わせた値をペナルティとして加え、その合計を最小にする係数を探します。この最小にする対象を目的関数と呼びます。ペナルティの強さ `alpha` は 1.0 にしました。

scikit-learn の Lasso は、係数を 1 つずつ動かして目的関数を下げる座標降下法（coordinate descent）で解き、`selection="random"` にすると、毎回どの係数を動かすかを乱数で選び、その乱数を seed で決めます。この seed だけを変えて 100 回当てはめました。比べるため、係数の 2 乗の和もペナルティに混ぜる [Elastic Net](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.ElasticNet.html) も同じ seed で当てはめます。

```python
def lasso_obj(m, alpha=1.0):
    return ((y - m.predict(Xs)) ** 2).sum() / (2 * n) + alpha * np.abs(m.coef_).sum()


def enet_obj(m, alpha=1.0, l1_ratio=0.9):
    w = m.coef_
    return (((y - m.predict(Xs)) ** 2).sum() / (2 * n)
            + alpha * l1_ratio * np.abs(w).sum() + 0.5 * alpha * (1 - l1_ratio) * (w ** 2).sum())


res = {"Lasso": [], "ElasticNet": []}
for seed in range(100):
    las = Lasso(alpha=1.0, selection="random", random_state=seed, tol=1e-10, max_iter=100000).fit(Xs, y)
    en = ElasticNet(alpha=1.0, l1_ratio=0.9, selection="random", random_state=seed,
                    tol=1e-10, max_iter=100000).fit(Xs, y)
    res["Lasso"].append((las.coef_[i_bmi], las.coef_[i_copy], lasso_obj(las)))
    res["ElasticNet"].append((en.coef_[i_bmi], en.coef_[i_copy], enet_obj(en)))
for name, r in res.items():
    r = np.array(r)
    res[name] = r
    print(f"{name:<10} bmi の係数 {r[:, 0].min():6.2f}〜{r[:, 0].max():6.2f}  "
          f"bmi_copy の係数 {r[:, 1].min():6.2f}〜{r[:, 1].max():6.2f}  "
          f"2 本の和 {(r[:, 0] + r[:, 1]).min():.4f}〜{(r[:, 0] + r[:, 1]).max():.4f}  "
          f"目的関数 {r[:, 2].min():.9f}〜{r[:, 2].max():.9f}")
```

```text
Lasso      bmi の係数   0.00〜 24.83  bmi_copy の係数   0.00〜 24.83  2 本の和 24.8315〜24.8315  目的関数 1533.768716963〜1533.768716963
ElasticNet bmi の係数  12.32〜 12.32  bmi_copy の係数  12.32〜 12.32  2 本の和 24.6308〜24.6308  目的関数 1584.754531427〜1584.754531427
```

{{< figure src="cvx_cover.webp" alt="2 枚の等高線図。横軸は bmi の係数、縦軸は bmi_copy の係数で、背景の濃い所ほど目的関数が低い。1 枚目の Lasso は、bmi と bmi_copy の係数の和が 24.83 になる斜めの線分に沿って谷底が平らで、seed を変えた 100 回の解の赤い点が (0, 24.83) から (24.83, 0) まで散らばる。2 枚目の Elastic Net は谷底が 1 点で、100 回の解の青い点が全て (12.32, 12.32) に重なる" caption="同じ列が 2 本ある diabetes で、seed を変えて 100 回解いた Lasso（左）と Elastic Net（右）の係数" align="center" >}}

Lasso では、bmi の係数が seed によって 0 から 24.83 までばらけました。2 本の係数を足すといつも 24.8315 で、最小にした目的関数の値は 100 回とも小数第 9 位まで同じ 1533.768716963 です。Elastic Net は、同じ 100 回で全て 12.32 ずつに分けました。2 本の和が 24.63 と Lasso より少し小さいのは、2 乗のペナルティが係数を 0 へ少し引き寄せるからです。

Lasso の係数から「どの列が効いているか」を説明すると、この 2 列では seed 次第で「bmi が効いている」とも「効いていない」とも言えてしまいます。Lasso はどの seed でも正しく最小を返していて、エラーも警告も出ません。

<br>

本記事では、ML の説明で「損失が凸なので」と書かれた所を自分で計算して確認したい人と、scikit-learn で線形モデルを使う人に向けて、次の疑問に答えます。

- 凸関数とは、どんな形の関数か。
- 凸なら、なぜ途中の谷で止まらないのか。
- 凸なのに、最小にする係数が 1 つに決まらないのはどんな時か。
- 凸かどうかと、最小の点が 1 つかどうかは、どう見分けるのか。
- 凸なら、どの学習率でも一番低い所に着くのか。
- 制約や期待値が付くと、凸関数はどう使われるのか。

実験は [NumPy](https://numpy.org/) 2.5.4 と scikit-learn 1.9.1 で行いました。図を描く処理も含めた完全なコードは [convex-functions_gen.py](https://github.com/nao1215/debimate/blob/main/projects/ml/scripts/notes/convex-functions_gen.py) にあります。

### 弦で見る凸関数

グラフ上の 2 点 `(a, f(a))` と `(b, f(b))` を結んだ線分を弦（chord）と呼びます。凸関数の定義域は、中の 2 点を結んだ線分がまた中に収まる集まりで、これを凸集合と呼びます。定義を式で書くと、定義域のどの `a`・`b` についても、`0 ≤ t ≤ 1` を満たす全ての `t` で `f(t a + (1 - t) b) ≤ t f(a) + (1 - t) f(b)` です。左辺は `a` と `b` に挟まれた点で関数が取る値、右辺はその位置で弦が通る高さです。

この定義のまま、4 つの関数で `a`・`b`・`t` を 10000 組選び、弦が関数より下に来た組と、弦が関数にぴったり重なった組を数えました。

```python
funcs = {
    "w²": lambda w: w ** 2,
    "|w|": lambda w: np.abs(w),
    "底が平ら": lambda w: np.maximum(np.abs(w) - 1, 0) ** 2,
    "谷が 2 つ": lambda w: w ** 4 - 2 * w ** 2 + 0.3 * w,
}
rng = np.random.default_rng(0)
a, b = rng.uniform(-2, 2, 10000), rng.uniform(-2, 2, 10000)  # 弦の両端
t = rng.uniform(0.05, 0.95, 10000)                             # 両端の間のどこを見るか
for name, f in funcs.items():
    curve = f(t * a + (1 - t) * b)
    chord = t * f(a) + (1 - t) * f(b)
    below = (curve > chord + 1e-12).sum()          # 弦が関数より下に来た組
    touch = (np.isclose(curve, chord, atol=1e-9) & (np.abs(a - b) > 0.1)).sum()  # 弦が関数に重なった組
    print(f"{name:<6} 弦が下: {below:5d} 組  弦が重なる: {touch:5d} 組（10000 組中）")
```

```text
w²     弦が下:     0 組  弦が重なる:     0 組（10000 組中）
|w|    弦が下:     0 組  弦が重なる:  4497 組（10000 組中）
底が平ら   弦が下:     0 組  弦が重なる:  2288 組（10000 組中）
谷が 2 つ 弦が下:  3094 組  弦が重なる:     2 組（10000 組中）
```

{{< figure src="cvx_shapes.webp" alt="4 枚のグラフ。1 枚目の w² は弦が両端以外で関数より上にあり、最小の点は w=0 の 1 つ。2 枚目の |w| は 0 で尖り、右側の直線の上に引いた弦は関数に重なる。最小の点は w=0 の 1 つ。3 枚目の底が平らな関数は w が -1 から 1 まで値が 0 で、弦がその平らな所に重なり、最小の点が区間に広がる。4 枚目の谷が 2 つある関数は、2 つの谷を結んだ赤い弦が山の部分で関数より下に来て、局所最小が 2 つある" caption="4 つの関数と弦。凸でない関数だけ、弦が関数より下に来る" align="center" >}}

谷が 2 つある関数だけ、3094 組で弦が関数より下に来たので、凸ではありません。残りの 3 つは凸です。凸関数のうち、両端以外で弦が関数に一度も重ならないものを狭義凸（strictly convex）と呼び、4 つの中では `w²` だけが当たります。

`|w|` は 0 で尖っていて微分できませんが、凸です。Lasso のペナルティはこの `|w|` を係数ごとに足したものです。ただ、`w` が同じ符号の範囲では直線なので、弦が関数に重なり、狭義凸ではありません。底が平らな関数も、`-1 ≤ w ≤ 1` で値が 0 のまま動かないので、最小の点が区間全体に広がります。

凸関数には、ほかに `exp(w)` や、`w > 0` での `-log(w)` があります。符号を反転した `-f` が凸になる `f` を凹関数（concave function）と呼び、`log(w)` は `w > 0` で凹です。直線 `a w + b` は弦がいつもグラフに重なるので、凸でもあり凹でもあります。定義と例は、Boyd 氏と Vandenberghe 氏が[凸関数を説明した講義資料](https://see.stanford.edu/materials/lsocoee364a/03ConvexFunctions.pdf)にまとまっています。

### 途中の谷で止まらない理由

勾配降下法のように少しずつ下る方法は、周りのどの向きに動いても値が下がらない点で止まります。この点を局所最小と呼び、関数全体で一番低い点を大域最小と呼びます。谷が 2 つある関数では、`w` が正の所にある浅い谷に入ると、`w` が負の所にもっと深い谷があっても抜け出せません。

凸関数では、局所最小は必ず大域最小です。仮に局所最小の点 `a` より低い点 `b` があれば、`a` から `b` へ引いた弦は `a` を出た直後から `f(a)` より低くなります。凸関数は弦より下にあるので、`a` のすぐ近くにも `f(a)` より低い点があることになり、`a` が局所最小であることと矛盾します。

微分できる凸関数では、どの点で引いた接線もグラフを下から支え、`f(b) ≥ f(a) + f'(a)(b - a)` が成り立ちます。`f'(a) = 0` なら右辺は `f(a)` なので、勾配が 0 の点はそのまま最小です。凸でない関数では、勾配が 0 でも極大や、`x² - y²` の原点のように向きによって上がったり下がったりする鞍点のことがあります。

冒頭の Lasso と、隠れ層に 10 個のユニットを持つ [MLPRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.neural_network.MLPRegressor.html) で、この違いを比べました。MLP は[多層パーセプトロン](../../ml/perceptron/)（multilayer perceptron）の略で、[活性化関数](../../ml/activation-functions/)を挟んで重みを掛け合わせるので、損失は重みについて一般に凸ではありません。元の 10 列の diabetes で seed を 20 個変え、止まった所の目的関数を記録します。

```python
X0 = StandardScaler().fit_transform(d.data)     # 元の 10 列
mlp_loss, iters = [], []
for seed in range(20):
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        m = MLPRegressor(hidden_layer_sizes=(10,), solver="lbfgs", max_iter=20000,
                         random_state=seed).fit(X0, y)
    mlp_loss.append(m.loss_)                    # 二乗誤差の半分の平均 + L2 のペナルティ
    iters.append(m.n_iter_)
mlp_loss = np.array(mlp_loss)
print("MLP の反復回数の最大:", max(iters), "（上限 20000）")
las_obj = res["Lasso"][:, 2]
for name, v in [("Lasso（100 回）", las_obj), ("MLP（20 回）", mlp_loss)]:
    gap = (v - v.min()) / v.min() * 100
    print(f"{name:<12} 最小 {v.min():9.3f}  最大 {v.max():9.3f}  最小との差の最大 {gap.max():.2e} %")
```

```text
MLP の反復回数の最大: 3285 （上限 20000）
Lasso（100 回） 最小  1533.769  最大  1533.769  最小との差の最大 5.93e-14 %
MLP（20 回）    最小   986.636  最大  1142.233  最小との差の最大 1.58e+01 %
```

MLPRegressor の `loss_` には、二乗誤差に加えて、重みの 2 乗の和を小さな強さで足した値が入っています。これを L2 のペナルティと呼び、係数ごとの絶対値を足す Lasso のペナルティは L1 のペナルティと呼びます。

{{< figure src="cvx_seeds.webp" alt="横軸は、止まった所の目的関数が一番低い seed より何 % 高いか。下の段の Lasso は seed 100 個の赤い点が全て 0 % に重なる。上の段の MLP は seed 20 個の青い点が 0 % から 15.8 % まで散らばる" caption="seed を変えた時に、止まった所の目的関数がどれだけ違うか" align="center" >}}

MLP は 20 回とも上限より前に止まったのに、止まった所の目的関数は一番低い seed より最大で 15.8 % 高くなりました。初期値によって別の谷に入ったと考えられます。Lasso は係数が 0〜24.83 にばらけても、目的関数の差は 1e-13 % 以下で、計算で生じる丸めの範囲に収まります。

凸でない場合に結果が初期値で変わる様子は、[k-means](../../ml/k-means/) でも実験しています。凸関数で seed を変えて変わるのは「同じ高さの谷底のどこに着いたか」で、凸でない関数で変わるのは「どの高さの谷に入ったか」です。

Lasso と MLP の差は、損失をどう組み立てたかで決まります。凸関数を 0 以上の重みで足した関数、入力を 1 次式で変換してから凸関数に入れた関数、凸関数どうしの max は、また凸です。

ロジスティック回帰の損失は、正解のラベルに付けた確率の log を符号を反転して足した値で、負の対数尤度と呼びます。線形回帰の二乗誤差も負の対数尤度も、1 次式 `Xw` を凸関数に入れて足した形なので、係数について凸です。L1・L2 のペナルティも凸なので、凸な損失に足しても凸のままです。

一方で、凸関数どうしを合成しても凸とは限りません。MLP の損失は活性化関数と重みの掛け算を重ねた合成なので一般に凸にならず、凸でない損失にペナルティを足すだけで凸になるとも限りません。

### 1 つに決まらない最小の点

凸関数で、最小の値を出す点を全て集めると、その集まりも凸集合になります。冒頭で Lasso が返した解の集まりは、`(0, 24.83)` と `(24.83, 0)` を結ぶ線分でした。

狭義凸なら、最小の点は多くても 1 つです。狭義凸関数で最小の点が 2 つあれば、その間の点は弦より真に低くなり、最小より低い値が出てしまうからです。逆は成り立たず、絶対値は狭義凸でなくても最小の点は 0 の 1 つだけです。この性質は、日本語版 Wikipedia で[凸関数](https://ja.wikipedia.org/wiki/%E5%87%B8%E9%96%A2%E6%95%B0)を説明した項目にも書かれています。

最小の点が複数あるのとは逆に、最小の点が存在しない凸関数もあります。`exp(w)` は狭義凸ですが、`w` を小さくするほど 0 に近づくだけで、0 になる点はありません。1 つに決まることと存在することは別の話です。ロジスティック回帰で、学習データの陽性と陰性を 1 本の直線で完全に分けられる時の損失がこの形で、[正則化を外した時の係数](../../ml/logistic-regression/#正則化を外した時の係数)が solver と `tol` で決まってしまう様子を実験しています。

存在を保証する条件の 1 つは、空でない閉じた有界な範囲で関数が連続であることです。Ridge のように係数を大きくするほどペナルティが増え続ける目的関数では、遠くの係数を調べる必要が無いので、この条件に当てはまる範囲だけを見ればよく、最小の点が存在します。

凸か、狭義凸か、最小の点がいくつあるかで、ここまでに出た関数を並べると次のようになります。

| 関数 | 凸 | 狭義凸 | 最小の点 |
|---|---|---|---|
| `w²` | 凸 | 狭義凸 | 1 つ |
| 絶対値 | 凸 | 狭義凸でない | 1 つ |
| 底が平ら | 凸 | 狭義凸でない | 区間に広がる |
| `exp(w)` | 凸 | 狭義凸 | 存在しない |
| 谷が 2 つ | 凸でない | 狭義凸でない | 局所最小が 2 つ |

Lasso の目的関数を式で書くと、二乗誤差の項 `(1/2n)|y - Xw|²` と、ペナルティ `α Σ|w_j|` の和です。`n` は行数の 442、`X` は 11 列を並べた行列、`y` は 1 年後の進み具合、`w` は係数を並べたもの、`α` はペナルティの強さ `alpha` です。`|y - Xw|²` は、予測と正解の差を 2 乗して全ての行で足した値です。

bmi と bmi_copy が同じ値なら、2 本の係数を足した値が同じである限り予測は変わらないので、二乗誤差の項は 2 本の分け方について平らです。ペナルティも、2 本が同じ符号なら `|w_bmi| + |w_copy|` は和のままで、やはり平らです。

Elastic Net は、このペナルティに係数の 2 乗の和を混ぜます。scikit-learn の式は `l1_ratio × α Σ|w_j| + 0.5 × (1 - l1_ratio) × α Σw_j²` で、`l1_ratio=0.9` なら `0.9 α Σ|w_j| + 0.05 α Σw_j²` です。2 乗の和は、和が同じなら 2 本に均等に分けた時が一番小さいので、谷底が 1 点に縮み、冒頭の図で Elastic Net が返したように 12.32 ずつに決まります。

scikit-learn が[線形モデルを説明した文書](https://scikit-learn.org/stable/modules/linear_model.html#elastic-net)にも、相関のある列が複数ある時、Lasso はその中から 1 つをランダムに選びやすく、Elastic Net は両方を選びやすい、と書かれています。相関が 0.9 程度の 2 列で、行を選び直すたびに Lasso が残す列が変わる様子は、[正則化](../../ml/regularization/)で実験しています。

### ヘッセ行列の固有値で見分ける

1 変数の関数なら、2 階微分が全ての点で 0 以上なら凸です。2 階微分は傾きの増え方なので、0 以上なら `w` が大きくなるほど傾きが急になり、グラフが上に開きます。全ての点で正なら狭義凸です。

多変数では、2 階の[偏微分](../partial-derivative-gradient/)を並べた行列であるヘッセ行列（Hessian matrix）を見ます。ヘッセ行列の固有値が全て 0 以上の時、どの向きに切った断面も上に開くので、関数は凸です。固有値が全て 0 以上の対称行列を半正定値（positive semidefinite）と呼びます。全ての点で固有値が全て正なら狭義凸で、0 の固有値があれば、その固有ベクトルの向きには曲がっていません。固有値と固有ベクトルは[固有値分解](../eigen-decomposition/)で説明しています。

二乗誤差の項 `(1/2n)|y - Xw|²` のヘッセ行列は `X^T X / n` で、`w` によらず一定です。どんな `X` でも固有値は 0 以上なので、二乗誤差の項はいつも凸です。冒頭の 11 列で固有値を求めました。

```python
H = Xs.T @ Xs / n                               # 二乗誤差の項 (1/2n)|y - Xw|^2 のヘッセ行列
eigvals, eigvecs = np.linalg.eigh(H)            # 昇順
print("固有値（小さい順に 3 つ）:", np.round(eigvals[:3], 6))
v0 = eigvecs[:, 0]
print("一番小さい固有値の固有ベクトルで 0.1 以上の成分:",
      {c: round(float(x), 3) for c, x in zip(X.columns, v0) if abs(x) > 0.1})
print("Elastic Net の L2 の項がヘッセ行列に足す値 alpha × (1 - l1_ratio) =", round(1.0 * (1 - 0.9), 3))
```

```text
固有値（小さい順に 3 つ）: [-0.        0.008561  0.078386]
一番小さい固有値の固有ベクトルで 0.1 以上の成分: {'bmi': -0.707, 'bmi_copy': 0.707}
Elastic Net の L2 の項がヘッセ行列に足す値 alpha × (1 - l1_ratio) = 0.1
```

一番小さい固有値は 0 で、その固有ベクトルは bmi が -0.707、bmi_copy が 0.707 でした。bmi の係数を減らした分だけ bmi_copy の係数を増やす向きで、冒頭の図で見た平らな谷底と同じ向きです。

{{< figure src="cvx_hessian.webp" alt="1 枚目は X^T X / n の 11 個の固有値を小さい順に並べた棒グラフで、1 番目はほぼ 0 の赤、2 番目は 0.0086、11 番目は 4.47。各棒の上に Elastic Net が足す 0.1 を緑で積み、1 番目も 0.1 になる。2 枚目は、2 本の係数を足した値を保ったまま bmi に配る係数を横軸にした断面で、赤の Lasso は 0 から 24.83 まで目的関数が最小値のまま平らで、外へ出ると直線で上がる。青の Elastic Net は 12.3 を底にした放物線" caption="ヘッセ行列の固有値と、固有値 0 の向きに切った目的関数の断面" align="center" >}}

Elastic Net の 2 乗のペナルティ `0.05 α w_j²` を 2 回微分すると `0.1 α` になります。棒グラフで緑に塗った部分のように、このペナルティはヘッセ行列が持つ全ての固有値に `α × (1 - l1_ratio)` の 0.1 を足します。一番小さい固有値も 0.1 になって全て正になるので、狭義凸です。[Ridge](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html) の `alpha` も同じ働きで、`alpha > 0` なら係数は 1 つに決まります。

Lasso のペナルティ `|w|` は、0 以外では直線なので 2 階微分が 0 で、ヘッセ行列に何も足しません。断面の赤い線が、0〜24.83 の間で平らなのはそのためです。区間の外では、片方の係数が負になって `|w|` の和が増え始め、直線で上がります。

`X^T X / n` の固有値が 0 になるのは、ある列が残りの列を定数倍して足した値で作れる時です。単位違いの列のほか、[カテゴリ変数のエンコーディング](../../ml/categorical-encoding/)で全てのカテゴリに列を作り、切片と一緒に使った時もこの形になります。逆に、列がそのような関係に無い時は、Lasso でも解は 1 つに決まります。Tibshirani 氏は[論文](https://doi.org/10.1214/13-EJS815)で、列の値が連続分布から出ている時は、確率 1 で Lasso の解が 1 つであることを示しています。

### 学習率の上限と、一番大きい固有値

凸関数でも、勾配降下法の学習率が大きすぎると発散します。1 変数の 2 次関数では、2 階微分を `λ` と書くと学習率を `2 / λ` 未満にする必要があり、その計算と実験は[最急降下法・SGD](../gradient-descent-sgd/)で扱っています。

多変数では、ヘッセ行列の一番大きい固有値 `L` が、一番急に曲がった向きの曲率です。その向きで発散しないためには、学習率を `2 / L` 未満にします。冒頭の 11 列の二乗誤差で、学習率を `1.0 / L`、`1.9 / L`、`2.05 / L` にして 300 回更新しました。切片は平均で決まるので、`y` から平均を引いて外しています。

```python
L = eigvals[-1]
Xc, yc = Xs, y - y.mean()                       # 切片は平均で決まるので、y から平均を引いて外す
w_ls = np.linalg.lstsq(Xc, yc, rcond=None)[0]
f_min = ((yc - Xc @ w_ls) ** 2).sum() / (2 * n)
curves = {}
for k in [1.0, 1.9, 2.05]:
    lr, w, hist = k / L, np.zeros(Xc.shape[1]), []
    for _ in range(300):
        w -= lr * Xc.T @ (Xc @ w - yc) / n      # 勾配は X^T (Xw - y) / n
        hist.append(((yc - Xc @ w) ** 2).sum() / (2 * n) - f_min)
    curves[k] = np.array(hist)
    print(f"学習率 {k:4.2f}/L = {lr:.3f}: 10 回目 {hist[9]:.3e}  300 回目 {hist[-1]:.3e}  "
          f"bmi {w[i_bmi]:.3g}  bmi_copy {w[i_copy]:.3g}")
print(f"L（一番大きい固有値）= {L:.3f}、2/L = {2 / L:.3f}")
```

```text
学習率 1.00/L = 0.224: 10 回目 1.822e+01  300 回目 3.558e+00  bmi 12.5  bmi_copy 12.5
学習率 1.90/L = 0.425: 10 回目 1.414e+02  300 回目 1.262e+00  bmi 12.4  bmi_copy 12.4
学習率 2.05/L = 0.459: 10 回目 2.857e+03  300 回目 5.546e+15  bmi -1.71e+07  bmi_copy -1.71e+07
L（一番大きい固有値）= 4.471、2/L = 0.447
```

{{< figure src="cvx_lr.webp" alt="横軸は更新の回数 1〜300、縦軸は目的関数と最小値の差で対数目盛。緑の学習率 1.00/L と青の 1.90/L は下がり続け、300 回目で 3.6 と 1.3。赤の 2.05/L は直線的に増え続け、300 回目で 5.5e15" caption="diabetes の二乗誤差を勾配降下法で下った時の、学習率と目的関数" align="center" >}}

上限の 0.447 を少し超えた 0.459 では、目的関数は 300 回で 5.5e15 まで増えました。目的関数が凸でも、1 回の歩幅が谷の幅より大きければ、谷を飛び越えるたびに遠ざかります。2 次関数でない滑らかな凸関数でも、最小の点が存在し、勾配の変わる速さに上限 `L` があれば、学習率を `1 / L` 以下にした勾配降下法は最小値に近づくことが、[勾配降下法の収束解析](https://www.stat.cmu.edu/~ryantibs/convexopt-F13/scribes/lec6.pdf)で示されています。

上限より下の 2 つは、300 回では最小値に届いていません。2 番目に小さい固有値が 0.0086 と小さく、その向きは谷がほぼ平らで、1 回で進む距離が短いからです。また、0 から出発した勾配降下法は、bmi と bmi_copy に同じ大きさの勾配が掛かるので、係数を 12.4〜12.5 ずつに分けました。この節の目的関数は二乗誤差だけで、ペナルティを含む Lasso とは違います。それでも bmi と bmi_copy で係数を分け合う向きには谷底が平らに続き、そのどこに着くかは解き方で決まります。

### 凸最適化の標準形

ここまでの目的関数では、係数がどんな値を取ってもかまいませんでした。凸最適化の標準形は、凸な `g_i(x) ≤ 0` と 1 次式の `A x = b` を全て満たす範囲で、凸な `f(x)` を最小にする問題です。制約を全て満たす点の集まりを実行可能集合と呼び、この形なら凸集合になるので、その中の局所最小は大域最小です。標準形の詳しい整理は、[凸最適化問題の講義資料](https://see.stanford.edu/materials/lsocoee364a/04ConvexOptimizationProblems.pdf)にあります。

{{< figure src="cvx_constraint.webp" alt="横軸 x が -1〜4、縦軸 (x - 2)² の放物線。x ≤ 1 の範囲を青く塗っている。灰色の点は制約が無い時の最小の x = 2 で微分は 0。赤い点は制約がある時の最小の x = 1 で、接線の傾きは -2。赤い矢印は、値が下がる右向きが制約の外にあることを示す" caption="制約 x ≤ 1 のもとで (x − 2)² を最小にした点" align="center" >}}

制約があると、最小の点で勾配が 0 になるとは限りません。`(x - 2)²` を `x ≤ 1` で最小にすると、解は `x = 1` で、微分は -2 です。値が下がる向きは制約の外にあり、そこで止まるからです。通常の勾配降下法はこの制約を知らないので、更新した点が範囲の外へ出たら範囲内で一番近い点へ戻す射影勾配法などを使います。[SVM](../../ml/svm/) のマージン最大化も、1 次式の制約が付いた凸な 2 次式の最小化です。

図の `x = 1` では、微分が -2 なので、関数は `x` を大きくする向きへ下ろうとします。制約 `x ≤ 1` がその力を 2 の強さで押し返し、2 つが釣り合っていると読めます。最小かどうかを判定するために、この釣り合いと制約をまとめた条件を KKT（Karush–Kuhn–Tucker）条件と呼びます。微分できる凸問題では、KKT 条件を満たす点は最小です。

逆に、最小の点が必ず KKT 条件を満たすと言うには、不等式制約を等号無しで満たす点があるという Slater 条件などの前提が要ります。条件の正確な形と Slater 条件は[双対性の講義資料](https://see.stanford.edu/materials/lsocoee364a/05Duality.pdf)で扱われています。

### 凸関数と期待値

凸関数は、期待値と組み合わせた時にも不等式を作ります。`f` が凸で期待値が有限なら、確率変数 `X` について `f(E[X]) ≤ E[f(X)]` が成り立ち、これを Jensen の不等式と呼びます。平均を取ってから `f` に入れた値は、`f` に入れてから平均を取った値を超えません。

2 点だけを取る `X` なら、左辺は弦の両端に挟まれた点で関数が取る値、右辺はその位置で弦が通る高さで、弦の節で見た凸関数の定義そのものです。`X` が -2〜2 の一様分布で `f(x) = x²` なら、左辺は `0² = 0`、右辺は `E[X²] = 4/3` です。この差を Jensen gap と呼び、`f(x) = x²` では差がちょうど[分散](../variance/)になります。`f` が狭義凸なら、`X` が定数でない限り等号は成り立ちません。

<br>

凹関数では不等号が逆になり、`log E[X] ≥ E[log X]` です。正の数 `a` と `b` を半々に取る `X` で書くと `log((a + b) / 2) ≥ (log a + log b) / 2` で、両辺を `exp` で戻すと相加平均と相乗平均の関係 `(a + b) / 2 ≥ sqrt(a b)` になります。

ML では、確率分布のずれを測る KL ダイバージェンスが 0 以上になることの証明に使われます。KL ダイバージェンスは[情報理論](../information-theory/)で扱っています。`log` を取った値の平均を `exp` で戻すと元の平均より小さく出る様子は、[期待値](../expectation/)で保険金のデータを使って実験しています。

### 係数を説明に使う前に

凸関数では、最小の点がある限り、どこから下っても同じ高さの谷底に着きます。谷底が 1 点かどうかは、もう 1 段強い狭義凸かで決まります。この 2 つで scikit-learn の線形モデルを分けると、次の表になります。

| モデル | 損失は係数について | 最小にする係数 |
|---|---|---|
| 線形回帰（最小二乗） | 凸 | 列が他の列から作れなければ 1 つ |
| Ridge（`alpha > 0`） | 狭義凸 | 1 つ |
| Lasso | 凸 | 他の列から作れる列があると広がることがある |
| Elastic Net（`l1_ratio < 1`） | 狭義凸 | 1 つ |
| ロジスティック回帰（L2 あり） | 狭義凸 | 1 つ |
| ロジスティック回帰（正則化なし） | 凸 | 完全に分けられると存在しない |
| 線形 SVM（hinge 損失と L2） | 凸 | 係数 `w` は 1 つ |
| MLP | 凸でない | 初期値で止まる谷が変わる |

Lasso の係数から列の効き目を説明する前には、まず `X^T X` の一番小さい固有値を見ます。0 に近ければ、その固有ベクトルで大きい成分の列どうしが、一方の列から他方をほぼ作れる組です。3 列以上の組み合わせのこともあります。冒頭の bmi と bmi_copy のように、どちらに係数が載るかは solver と seed の都合なので、組の列は 1 つにまとめるか、Elastic Net や Ridge で係数を分けさせます。

一番小さい固有値が小さく、0 とは言い切れない時は、Lasso の `selection="random"` で seed を数個変えて当てはめれば、係数が動くかを直接見られます。目的関数の値が同じまま係数が動けば谷底が平らで、目的関数の値まで変わるなら、MLP のように凸でないか、収束していない可能性があります。冒頭の図で Lasso のように点が線分に並ぶか、Elastic Net のように 1 点に集まるかが、係数を読んでよいかの目安になります。

どちらの場合も、凸性が教えてくれるのは学習データの上で最小を求めた結果だけです。データが大きい時に必要なメモリや計算時間も凸性からは分からず、列の数や疎かどうか、求める精度で決まります。その係数が未知のデータでも当たるかは、[過学習](../../ml/overfitting/)として別に評価します。

仮説検定（hypothesis testing）は、手元で見えた差が、本当は差が無くても偶然に出る程度の大きさかどうかを確率で判断する手順です。例えば、2 つのモデルでクリック率に差が出た時に使います。

「差が無い」という仮定を帰無仮説（null hypothesis）と呼び、帰無仮説が正しいとした時に、手元と同じかそれより大きな差が偶然に出る確率を p 値と呼びます。p 値が前もって決めた有意水準（significance level）を下回ったら「有意」と呼び、差があると判断します。有意水準には、慣習で 0.05 がよく使われます。

利用者を 2 つの群に分けて片方に新しい推薦モデル、もう片方に旧モデルを使い、クリック率などを比べる実験を A/B テストと呼びます。A/B テストで新しいモデルを採用するか決める時や、[交差検証](../../ml/cross-validation/)のスコアで 2 つのモデルを比べる時、この 0.05 について次のように考えがちです。

- p < 0.05 なら、差が偶然である確率は 5% 未満
- 途中で何度 p 値を見ても、誤る割合は 5% のまま
- p > 0.05 なら、2 つのモデルに差は無い
- 交差検証を繰り返してスコアを増やすほど、検定は正確になる

どれも成り立ちません。2 つ目を試すため、クリック率が同じ 5% の 2 つのモデルで、1 日にモデルごとに 1000 人ずつ集める 28 日の A/B テストを 10000 本作り、毎日その日までの累計で検定しました。

28 日目に 1 回だけ検定すると、差が無いのに有意になったのは 5.0% で、有意水準のとおりでした。毎日 p 値を見て、0.05 を下回った日に止めると、26.8% が有意になります。途中で一度下回った実験のうち 81.3% は、28 日目まで続けていれば 0.05 より上に戻っていました。

<br>

本記事では、ML の評価で p 値や信頼区間を自分で計算したい人と、A/B テストで 2 つのモデルを比べた結果を読む人に向けて、次の疑問に答えます。

- p 値は、何の割合を表すのか。
- 有意になった施策のうち、本当は差が無いものはどれだけあるのか。
- 途中で何度も p 値を見ると、なぜ誤りが増えるのか。
- p > 0.05 の時、差が無いと言ってよいのか。
- 95% 信頼区間の 95% は何の割合で、t 分布はなぜ要るのか。
- 交差検証で得たスコアの差を t 検定すると、何が起きるのか。

実験は [NumPy](https://numpy.org/) 2.5.4、[SciPy](https://scipy.org/) 1.18.1、[scikit-learn](https://scikit-learn.org/stable/) 1.9.1 で行いました。図を描く処理も含めた完全なコードは [hypothesis-test_gen.py](https://github.com/nao1215/debimate/blob/main/projects/ml/scripts/notes/hypothesis-test_gen.py) にあります。

### 差が無い時の p 値

冒頭の A/B テストでは、差が無い時に見込まれるばらつきで 2 つのクリック率の差を割った数 `z` を使いました。このばらつきを標準誤差と呼び、2 つの群を合わせたクリック率 `p_pool` と各群の人数 `n` から `√(p_pool (1 - p_pool) × 2 / n)` で求めます。この手順は、2 群の割合を比べる z 検定と呼ばれます。

差が無くても、実験を作り直すたびに `z` は 0 の周りに散らばります。人数が多ければ、その散らばり方は平均 0、標準偏差 1 の[正規分布](../probability-distributions/)にほぼ従います。この分布の上に手元の実験で計算した `z` を立て、それより 0 から遠い両側の裾を塗ります。塗った面積を合わせたものが、両側の p 値です。

{{< figure src="hypo_z_area.webp" alt="平均 0、標準偏差 1 の正規分布の山。横軸は差が無い時の z。手元の z = 1.52 と、反対側の -1.52 に赤い縦線があり、1.52 より右と -1.52 より左の裾が赤く塗られている。両側の赤い面積の合計が p 値 0.128" caption="差が無い時に z が散らばる分布と、手元の z より外側の面積（p 値）" align="center" >}}

図は 10000 本のうち 1 本の 28 日目で、`z` は 1.52 でした。差が無くてもこれより 0 から遠い `z` は両側で 12.8% 出るので、p 値は 0.128 です。両側の裾が合わせて 5% になるのは `|z|` が 1.96 を超える所なので、p < 0.05 は `|z| > 1.96` と同じ意味です。

`z` のように、データから計算し、帰無仮説が正しい時の分布が分かっている数を検定統計量と呼びます。帰無仮説を否定する「差がある」という主張は対立仮説（alternative hypothesis）と呼び、B が A と違うとする両側にするか、B が A より高いとする片側にするかはデータを見る前に決めます。本記事は両側で計算しています。

なお、人数は利用者ごとに数えます。同じ利用者のクリックを何度も数えると、1 件ずつ別の偶然で決まるという z 検定の前提が崩れ、p 値が小さく出すぎます。

```python
DAYS, PER_DAY = 28, 1000          # 28 日、1 日に 1 つのモデルあたり 1000 人


def ab_test(rate_a, rate_b, n_exp, rng):
    """n_exp 本の A/B テストを作り、各日までの累計で 2 群の割合の z 検定をした p 値を返す。"""
    a = rng.binomial(PER_DAY, rate_a, size=(n_exp, DAYS)).cumsum(axis=1)  # A をクリックした累計
    b = rng.binomial(PER_DAY, rate_b, size=(n_exp, DAYS)).cumsum(axis=1)
    n = PER_DAY * np.arange(1, DAYS + 1)                                   # 各日までの累計人数
    pooled = (a + b) / (2 * n)                                             # 差が無いとした時のクリック率
    se = np.sqrt(pooled * (1 - pooled) * 2 / n)
    z = (b / n - a / n) / se
    return 2 * stats.norm.sf(np.abs(z))                                    # 両側の p 値


rng = np.random.default_rng(0)
p_null = ab_test(0.05, 0.05, 10000, rng)    # 2 つともクリック率 5%
p_lift = ab_test(0.05, 0.055, 10000, rng)   # B のクリック率が 5.5%（1 割増し）
```

10000 本について、28 日目の p 値を 0.05 刻みで数えたのが次の図です。

{{< figure src="hypo_pvalue_hist.webp" alt="2 枚のヒストグラム。横軸は 28 日目の p 値で 0 から 1 を 0.05 刻み、縦軸は 10000 本のうちの実験の数。左の差が無い場合は、どの幅にもほぼ 500 本ずつ平らに並び、0〜0.05 の赤い棒も 500 本で、p < 0.05 の割合は 5.0%。右の B が 5.5% の場合は、0〜0.05 の赤い棒が 7593 本と高く、0.05 より右は急に減る。p < 0.05 の割合は 75.9%" caption="差が無い時と、B が 1 割高い時の p 値の分布（10000 本）" align="center" >}}

差が無い時、p 値は 0 から 1 に均等に散らばり、どの 0.05 の幅にも約 500 本が入ります。p 値は差が無い時の分布で手元より外側にある面積なので、差が無ければ p < 0.05 になる実験は定義どおり 5% です。有意水準 0.05 は、差が無い時に誤って有意とする割合を 5% に抑えるという取り決めで、この誤りを第一種の誤り（type I error）と呼びます。

差がある右の図では p 値が 0 の近くに集まり、75.9% が有意になりました。逆に言えば、差があるのに 24.1% は有意になりません。この見逃しを第二種の誤り（type II error）と呼びます。

p 値は、帰無仮説が正しいと仮定した上での確率です。帰無仮説が正しい確率でも、見えた差が偶然である確率でもないことは、[米国統計学会の 2016 年の声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)でも 6 つの原則の 1 つとして挙げられています。同じ声明は、閾値を越えたかどうかだけで結論を決めないことも求めています。p 値が 0.049 と 0.051 の 2 つの実験は、ほぼ同じ強さの証拠です。

### 有意になった施策の内訳

冒頭の 1 つ目の思い込みは、「差が無い施策のうち、有意になる割合」と「有意になった施策のうち、差が無い割合」を取り違えています。違いを見るため、1000 本の施策のうち 100 本だけが本当にクリック率を 1 割上げ、残りの 900 本は差が無いと仮定しました。それぞれの施策が有意になる割合は、前の節で 10000 本から数えた 5.0% と 75.9% を使います。

```python
rate_null = (p_null[:, -1] < 0.05).mean()     # 差が無い施策が有意になる割合（10000 本から）
rate_true = (p_lift[:, -1] < 0.05).mean()     # 1 割増しの施策が有意になる割合
n_null_sig = round(900 * rate_null)           # 900 本は差が無い施策
n_true_sig = round(100 * rate_true)           # 100 本は 1 割増しの施策
print(f"有意になった施策: {n_null_sig + n_true_sig} 本（差が無い {n_null_sig} 本、差がある {n_true_sig} 本）")
print(f"有意のうち差が無かった割合: {n_null_sig / (n_null_sig + n_true_sig):.1%}")
```

```text
有意になった施策: 121 本（差が無い 45 本、差がある 76 本）
有意のうち差が無かった割合: 37.2%
```

{{< figure src="hypo_base_rate.webp" alt="1000 個のマス。左の 900 マスは差が無い施策で、そのうち 45 マスが濃い赤（差が無いのに有意）、残りは薄い赤。右の 100 マスは差がある施策で、76 マスが青（差があり有意）、24 マスが薄い青（差があるのに有意でない）" caption="1000 本の施策のうち、有意になった 121 本の内訳" align="center" >}}

有意になった 121 本のうち、45 本、37.2% は差の無い施策でした。図の濃い赤のマスが第一種の誤り、薄い青のマスが第二種の誤りです。差の無い施策のうちで有意になるのは 5% でも、差の無い施策の方が 9 倍多いので、有意の中に占める割合は 5% よりずっと大きくなります。

この割合は、試す施策のうち本当に効くものがどれだけあるかで変わります。効く施策が 1000 本に 10 本しか無ければ、`990 × 5.0% = 49.5` 本と `10 × 75.9% = 7.6` 本で、有意になった施策の 87% は差がありません。

病気の検査で、陽性の人が本当に病気である確率が有病率で変わるのと同じ計算で、[ベイズの定理](../bayes-theorem/)で説明しています。Ioannidis 氏の [2005 年の論文](https://doi.org/10.1371/journal.pmed.0020124)は、この計算を研究の発見に当てはめ、効く仮説の割合が低く、差があっても有意になりにくい分野では、有意と報告された結果の多くが誤りになりうると論じました。

### 途中で何度も見る

冒頭の動く図では、差の無い実験の p 値が、日ごとに 0.01 から 1 近くまで上下していました。累計の人数が増えても、差が無い時の p 値は 0 から 1 のどこにでも出ます。毎日 0.05 と比べるのは、5% で当たるくじを 28 回引くのに近い行為です。

ただし、前日の累計に 1 日分を足しただけなので、隣り合う日の p 値は似た値になります。そのため、28 回を互いに無関係に引いた時の `1 - 0.95^28 = 76%` までは増えません。

見る回数を 28 日の中で等間隔に変えて、差が無いのに一度でも 0.05 を下回った割合を調べました。0.05 を見る回数で割る、Bonferroni 補正と呼ばれる手も並べています。

```python
looks_list = [1, 2, 4, 7, 14, 28]
naive, bonf = [], []
for looks in looks_list:
    days = np.linspace(DAYS / looks, DAYS, looks).round().astype(int) - 1  # 見る日（等間隔）
    naive.append((p_null[:, days] < 0.05).any(axis=1).mean())
    bonf.append((p_null[:, days] < 0.05 / looks).any(axis=1).mean())    # 見る回数で 0.05 を割る
    print(f"{looks:2d} 回見る: 0.05 のまま {naive[-1]:.1%}  0.05/{looks} にする {bonf[-1]:.1%}")
```

{{< figure src="hypo_looks.webp" alt="棒グラフ。横軸は 28 日のうち p 値を見る回数で 1、2、4、7、14、28 回。赤い棒は毎回 0.05 と比べた時の、差が無いのに有意になる割合で、5.0%、8.4%、12.4%、16.4%、21.5%、26.8% と増える。青い棒は 0.05 を見る回数で割った時で、5.0%、4.5%、3.9%、3.2%、2.4%、1.7% と減る。5% に点線" caption="p 値を見る回数と、差が無いのに有意になる割合" align="center" >}}

2 回見るだけで 8.4%、週 1 回の 4 回で 12.4% になりました。データが溜まるたびに検定を繰り返すと誤りが増えることは、Armitage 氏らの [1969 年の論文](https://doi.org/10.2307/2343787)が計算で示しています。A/B テストの文脈では、Evan Miller 氏の [How Not To Run an A/B Test](https://www.evanmiller.org/how-not-to-run-an-ab-test.html) が、150 人まで 1 人増えるたびに見て止めると 26.1% になる例を挙げています。

Bonferroni 補正は 5% を下回りますが、28 回で 1.7% と、必要以上に厳しくなります。厳しくした分、差があっても見つけにくくなるので、B が 1 割高い時に有意になる割合も同じ 10000 本で比べました。

| 見方 | 差が無い時に有意 | B が 1 割高い時に有意 |
|---|---|---|
| 28 日目に 1 回、0.05 | 5.0% | 75.9% |
| 毎日、0.05 | 26.8% | 86.0% |
| 毎日、0.05 / 28 | 1.7% | 42.0% |
| 週 1 回、0.05 / 4 | 3.9% | 62.5% |

毎日 0.05 で見ると差がある時も 86.0% と多く見つかりますが、その分だけ差が無い時の誤りも 26.8% に増えています。

途中で止めたい時は、見る日と、その日ごとに比べる値を前もって決めておく逐次検定を使います。[Pocock 氏の方法](https://doi.org/10.1093/biomet/64.2.191)はどの日も同じ閾値を使い、[O'Brien 氏と Fleming 氏の方法](https://doi.org/10.2307/2530245)は初めの日ほど厳しい閾値を使います。どちらも隣り合う日の p 値が似ていることを織り込んで閾値を決めるので、Bonferroni 補正ほど厳しくなりません。Johari 氏らの [Always Valid Inference](https://arxiv.org/abs/1512.04922) は、いつ見ても誤りが 5% に収まる p 値を作る方法で、A/B テストのサービスに向けて提案されました。

#### 見る指標を増やす

同じことは、見る指標の数でも起きます。クリック率・滞在時間・購入率のように、差の無い独立した指標を 20 個見てどれか 1 つが有意になる割合は、`1 - 0.95^20 = 64%` です。[データドリフトの監視](../../mlops/data-drift/)で、2 つのデータの分布が同じかを比べる [KS 検定](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ks_2samp.html)を列ごとにして 0.05 でアラートを出す時も、列が多いほど、変化が無くてもどれかの列で鳴ります。

判断に使う指標は 1 つに決めておき、複数を見るなら Bonferroni 補正のように閾値を割ります。Bonferroni 補正より厳しすぎない方法には、Holm 氏の方法や、有意とした中に含まれる誤りの割合を抑える [Benjamini 氏と Hochberg 氏の方法](https://doi.org/10.1111/j.2517-6161.1995.tb02031.x)があり、後者は SciPy の [`false_discovery_control`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.false_discovery_control.html) で計算できます。

### 有意にならない差

3 つ目の思い込みの「p > 0.05 なら差は無い」は、見方を比べた表の 1 行目で崩れています。B が本当に 1 割高くても、28 日目に 1 回だけ検定すると 24.1% の実験は p > 0.05 でした。差があった時に有意になる割合を検定力（power）と呼び、差の大きさと人数で決まります。

正規分布の近似を使うと、検定力は式で求まります。差 `δ` を差がある時の標準誤差で割った数を `shift` とすると、`z` は平均 `shift`、標準偏差 1 の正規分布に従うので、検定力は `|z| > 1.96` になる確率です。

```python
day_axis = np.arange(1, 57)
for rate_b in [0.06, 0.055, 0.0525]:
    n = PER_DAY * day_axis
    se = np.sqrt((0.05 * 0.95 + rate_b * (1 - rate_b)) / n)
    shift = (rate_b - 0.05) / se
    power = stats.norm.sf(1.96 - shift) + stats.norm.cdf(-1.96 - shift)
```

{{< figure src="hypo_power.webp" alt="横軸は経過日数 1〜56 日で 1 日に 1 つのモデルあたり 1000 人、縦軸はその日に 1 回検定して有意になる割合（検定力）。緑の B が 6.00%（20% 増し）は 9 日目に 80% の点線を越え、20 日でほぼ 100%。青の B が 5.50%（10% 増し）は 28 日目に 75.6% で、その位置にシミュレーションの 75.9% の点がある。80% を越えるのは 32 日目。赤の B が 5.25%（5% 増し）は 28 日目に 26.9%、56 日目でも 50% に届かない" caption="差の大きさごとの検定力と、集めた日数" align="center" >}}

28 日目の点は、式で求めた 75.6% と、前の節で 10000 本を数えた 75.9% がほぼ重なります。クリック率が 5% 増しの 5.25% なら、28 日続けても検定力は 26.9% で、4 本に 3 本は差を見逃します。56 日でも 50% に届きません。この場合の p > 0.05 は、差が無いことではなく、この人数では区別できなかったことを示します。

有意水準を 0.05 から小さくすると、第一種の誤りは減りますが、検定力も下がって第二種の誤りが増えます。見方を比べた表で、0.05 を 28 で割った行の検定力が 42.0% まで落ちたのと同じです。両方を減らすには人数を増やします。

検定力 80% に要る 1 群の人数は、`n = ((1.96 + 0.84) × σ_d / δ)²` で逆算できます。`σ_d` は 1 人あたりの差のばらつきで、クリック率なら `√(p_A (1 - p_A) + p_B (1 - p_B))`、0.84 は標準正規分布の 80% 点です。この逆算を検定力分析（power analysis）と呼びます。

逆に人数を増やせば、どんなに小さな差でも有意になります。同じ式で、5% を 1% 増しの 5.05% にした差でも、モデルごとに約 300 万人を集めれば検定力は 80% になります。有意かどうかは差の大きさを表さないので、差がどれだけあるかは、差の大きさそのものを表す効果量（effect size）や、次の節で扱う信頼区間で示します。効果量には、平均の差を標準偏差で割った Cohen の d などがあります。

### 信頼区間と t 分布

95% 信頼区間（confidence interval）は、手元のデータから作る「平均 ± 何倍かの標準誤差」の区間で、同じ手順でデータを取り直して区間を作り直すと、そのうち 95% の区間が真の値を含むように幅を決めます。標準誤差は `√n` に反比例するので、人数を 4 倍にすると区間の幅は半分になります。95% は区間を作る手順が当たる割合で、手元で計算した 1 本の区間に真の値が入る確率ではありません。

1 本の区間に入る確率として述べられるのは、[ベイズの定理](../bayes-theorem/)で事前分布を置いて作る信用区間（credible interval）の方です。実データで当たる割合を数えた実験と、裾の重いデータで外れる例は、[大数の法則と中心極限定理](../lln-clt/)で扱っています。

信頼区間と検定は、同じ計算から作ります。平均が 0 かどうかを調べる 1 標本の t 検定は、下の小見出しで説明する t 分布を使う検定で、0 が 95% 信頼区間の外にあることと、p < 0.05 が必ず一致します。真の平均を 0.3 にした 10 件のデータを 10000 回作って調べました。

```python
x = rng.normal(loc=0.3, size=(10000, 10))
m, s = x.mean(axis=1), x.std(axis=1, ddof=1)
half = stats.t.ppf(0.975, 9) * s / np.sqrt(10)
outside = np.abs(m) > half
p = stats.ttest_1samp(x, 0, axis=1).pvalue
print(f"0 が区間の外と p < 0.05 が一致した回数: {np.sum(outside == (p < 0.05))} / 10000")
```

```text
0 が区間の外と p < 0.05 が一致した回数: 10000 / 10000
```

検定の結果を「有意」「有意でない」の 2 つで報告するより、差の区間を報告する方が、差の大きさと不確かさを一緒に伝えられます。区間が 0 をまたがなければ有意で、区間の幅が狭いほど、差の大きさがはっきりしています。[ロジスティック回帰](../../ml/logistic-regression/)や[線形回帰](../../ml/linear-regression/)の係数に付く「係数 ± 1.96 × 標準誤差」も同じ形の区間で、0 をまたぐ係数は 5% の水準で 0 と区別できません。

<br>

#### σ の代わりに s を使う

上記のコードでは、区間の幅に 1.96 ではなく `stats.t.ppf(0.975, 9)` の 2.26 を掛けています。平均の標準誤差は、本当は母集団の[標準偏差](../stddev/) `σ` から `σ / √n` で求めますが、`σ` は分からないので、手元の `n` 件から計算した標本の標準偏差 `s` で代わりにします。`s` も件数が少ないと揺れ、小さく出た時に区間が狭くなりすぎるので、1.96 のままでは 95% に届きません。

正規分布から `n` 件を取り、1.96 を掛けた区間と、自由度 `n - 1` の [t 分布](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.t.html)の 97.5% 点を掛けた区間で、真の平均を含んだ割合を 20000 回ずつ調べました。

```python
ns = [3, 4, 5, 7, 10, 15, 20, 30, 50]
cover_z, cover_t = [], []
for n in ns:
    x = rng.normal(size=(20000, n))            # 真の平均は 0
    m, s = x.mean(axis=1), x.std(axis=1, ddof=1)
    half_z = 1.96 * s / np.sqrt(n)
    half_t = stats.t.ppf(0.975, n - 1) * s / np.sqrt(n)
    cover_z.append(np.mean(np.abs(m) <= half_z))
    cover_t.append(np.mean(np.abs(m) <= half_t))
```

{{< figure src="hypo_t_vs_z.webp" alt="横軸は件数 n（3、4、5、7、10、15、20、30、50）、縦軸は区間が真の平均を含んだ割合。赤い平均 ± 1.96 × s / √n は n=3 で 81.3%、n=4 で 85.7%、n=5 で 87.7% と低く、n=50 で 94.4% まで上がる。青い平均 ± t × s / √n（自由度 n - 1）はどの n でも 95% の点線にほぼ重なる（94.7〜95.2%）" caption="1.96 を掛けた区間と、t 分布の値を掛けた区間が当たる割合" align="center" >}}

1.96 を使うと、3 件で 81.3%、5 件で 87.7% しか当たりません。t 分布の 97.5% 点は 3 件で 4.30、5 件で 2.78 と、件数が少ないほど大きく、どの件数でもほぼ 95% 当たりました。t 分布は Gosset 氏が Student の名で [1908 年に発表](https://www.jstor.org/stable/2331554)したもので、元のデータが正規分布に従う時に、`s` の揺れを含めた区間の幅を正しく与えます。30 件で 94.0% と、件数が多ければ 1.96 との差は小さくなります。

2 つの群の平均を比べる 2 標本の t 検定は、SciPy の [`ttest_ind`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html) で計算できます。既定の `equal_var=True` では、2 群の[分散](../variance/)が等しいと仮定します。分散も人数も違う時は、`equal_var=False` を渡して [Welch の t 検定](https://doi.org/10.1093/biomet/34.1-2.28)にします。

ML で件数が少ないのは、交差検証の分割ごとのスコアです。5 分割なら 5 個、10 分割なら 10 個のスコアから平均と幅を出すので、t 分布を使います。

### 交差検証で得たスコアの差

交差検証は、データを `k` 個に分け、1 個をテストに、残りを学習に使うことを `k` 回繰り返す評価です。2 つのモデルを同じ分け方で評価すると、分割ごとに正解率の差が 1 個ずつ得られます。差を取ってから平均が 0 かを調べる 1 標本の t 検定は、同じ分割で得た 2 つのスコアを組にして比べる、対応のある t 検定と同じ計算です。10 分割を 10 回繰り返せば差は 100 個になり、この 100 個に t 検定をすれば、10 個の時より細かい差まで分かりそうに見えます。

2 つのモデルの性能が本当に等しい場面を作るため、10 列のうち 0〜2 列目と 5〜7 列目が同じ強さで正解のラベルに効くデータを 200 行作りました。モデル A は前半の 5 列、モデル B は後半の 5 列で[ロジスティック回帰](../../ml/logistic-regression/)を学習するので、前半と後半を入れ替えても同じデータの作り方になり、性能は等しくなります。データの作り直しを 300 回繰り返し、毎回 p < 0.05 になるかを調べました。

```python
N_ROWS, N_DATA, K = 200, 300, 10


def make_data(rng):
    """10 列のうち 0〜2 列目と 5〜7 列目が同じ強さで y に効く。前半と後半は対称。"""
    X = rng.normal(size=(N_ROWS, 10))
    logit = X[:, [0, 1, 2]].sum(axis=1) + X[:, [5, 6, 7]].sum(axis=1)
    y = (rng.random(N_ROWS) < 1 / (1 + np.exp(-logit))).astype(int)
    return X, y


p_cv = {"100 個に t 検定": [], "補正した t 検定": [], "10 分割 1 回の 10 個に t 検定": []}
for r in range(N_DATA):
    X, y = make_data(rng)
    cv = RepeatedStratifiedKFold(n_splits=K, n_repeats=10, random_state=r)
    acc_a = cross_val_score(LogisticRegression(), X[:, :5], y, cv=cv)  # モデル A は前半の 5 列
    acc_b = cross_val_score(LogisticRegression(), X[:, 5:], y, cv=cv)  # モデル B は後半の 5 列
    diff = acc_a - acc_b                                               # 100 個の差
    p_cv["100 個に t 検定"].append(stats.ttest_1samp(diff, 0).pvalue)
    p_cv["10 分割 1 回の 10 個に t 検定"].append(stats.ttest_1samp(diff[:K], 0).pvalue)
    n_train, n_test = N_ROWS * (K - 1) // K, N_ROWS // K
    var = np.var(diff, ddof=1) * (1 / len(diff) + n_test / n_train)  # Nadeau と Bengio の補正
    t = diff.mean() / np.sqrt(var)
    p_cv["補正した t 検定"].append(2 * stats.t.sf(abs(t), len(diff) - 1))
```

```text
100 個に t 検定: 差が無いのに p < 0.05 になった割合 57.0%
補正した t 検定: 差が無いのに p < 0.05 になった割合 4.7%
10 分割 1 回の 10 個に t 検定: 差が無いのに p < 0.05 になった割合 5.0%
```

{{< figure src="hypo_cv.webp" alt="横棒グラフ。差の無い 2 つのモデルで p < 0.05 になった割合（300 個のデータセット）。赤い 10 分割 × 10 回の 100 個に t 検定は 57.0%。青い 100 個に補正した t 検定は 4.7%、青い 10 分割 1 回の 10 個に t 検定は 5.0%。5% に点線" caption="交差検証で得たスコアの差に t 検定をかけた時、差が無いのに有意になる割合" align="center" >}}

100 個の差にそのまま t 検定をかけると、性能が等しいモデルの組のうち 57.0% で有意になりました。スコアを増やすほど正確になるどころか、半分以上の組で誤ります。t 検定は 100 個の差どうしが独立だと仮定し、標準誤差を `s / √100` まで小さくします。ところが 100 個の差は、同じ 200 行を分け直して作ったものです。同じ回の 10 分割では、どの 2 つの学習データも行の 9 分の 8 を共有し、回をまたいでも同じ 200 行から作ります。100 個に増やしても、データを取り直した時の揺れは 200 行分のままです。

Nadeau 氏と Bengio 氏の [2003 年の論文](https://doi.org/10.1023/A:1024068626366)は、分散に掛ける `1 / 100` を `1 / 100 + テストの行数 / 学習の行数` に置き換えて、この共有分を足す補正を提案しました。この実験では `1 / 100 + 20 / 180` で、`1 / 100` の 12 倍の分散になり、誤る割合は 4.7% に戻りました。

scikit-learn の [Statistical comparison of models using grid search](https://scikit-learn.org/stable/auto_examples/model_selection/plot_grid_search_stats.html) も、モデルの比較にこの補正を使っています。2 つのモデルの差が実用上無視できる範囲に入る確率を出す、[ベイズ流の比較](https://jmlr.org/papers/v18/16-305.html)を Benavoli 氏らが提案しています。

10 分割 1 回の 10 個に t 検定をかけた場合は、この実験では 5.0% でした。Dietterich 氏の [1998 年の論文](https://doi.org/10.1162/089976698300017197)は、10 分割の t 検定は第一種の誤りがやや大きくなりうると報告し、2 分割を 5 回繰り返す 5×2 cv 検定を提案しています。

### 検定を始める前に決めること

冒頭の動く図で赤くなった線の多くは、28 日目には 0.05 より上に戻っていました。どの日に止めても p 値は 1 つ出てきて、SciPy もダッシュボードも警告を出しません。有意水準が誤りの割合を表すのは、p 値を何回、どの日に見るかを前もって決め、そのとおりに検定した時だけです。

A/B テストを始める前に、意味があると考える最小の差を決め、検定力の図と同じ計算で、その差を 80% ほどの確率で見つけられる人数と日数を出します。1 割の差なら、この例では 32 日です。判断に使う指標を 1 つに絞り、見る日を決めます。途中で止めたいなら、毎回 0.05 と比べずに、Bonferroni 補正か逐次検定の閾値を使います。

結果は p 値だけでなく、差の信頼区間で報告します。p > 0.05 で区間が広ければ、差が無いのではなく人数が足りなかったと読みます。交差検証でモデルを比べる時は、繰り返したスコアにそのまま t 検定をかけず、Nadeau と Bengio の補正をした t 検定か 5×2 cv 検定を使います。どの場面でも、冒頭の動く図で見た 26.8% と 5.0% の差が、手順を決めずに見た時と決めて見た時の差です。

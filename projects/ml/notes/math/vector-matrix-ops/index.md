機械学習では、1 件のデータを特徴量ベクトル、複数件のデータを行列として扱います。線形回帰の `X @ w` は、各データと重みの内積をまとめて計算する式です。各行を 1 件のデータ、各列を 1 種類の特徴量として並べると、全データの予測値を一度に計算できます。

<br>

本記事では、実数のベクトルの加算・スカラー倍、内積、行列積を説明します。掲載コードは[生成コード](https://github.com/nao1215/debimate/blob/main/projects/ml/scripts/notes/vector-matrix-ops_gen.py)から描画を除いた抜粋で、2 つ目以降のブロックも最初の `import numpy as np` を前提にします。[NumPy の `matmul`](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html)は、ここで使う `@` 演算子と対応します。

---

### ベクトル: 加算・スカラー倍

ベクトルは数を順序付きで並べたもので、同じ次元のベクトル同士なら要素ごとに加算できます。例えば、`a = (3, 1)` と `b = (1, 2)` の和は `(4, 3)` です。

スカラー倍はすべての要素を同じ数 `k` 倍する操作です。非零のベクトルに対して、正の `k` は向きを保って長さを変え、負の `k` は向きを反転させます。`k = 0` なら、向きを持たない零ベクトルになります。

```python
import numpy as np

a = np.array([3, 1])
b = np.array([1, 2])
c = a + b  # [4, 3]
v = np.array([2, 1])
scaled = [k * v for k in [1.5, 1.0, -1.0]]
```

{{< figure src="vector_basics.svg" alt="上はベクトル加算で、a = (3, 1) の終点に b = (1, 2) の始点を継ぎ足すと、原点からその終点への矢印が a + b = (4, 3) になる。下はスカラー倍で、v = (2, 1) に対して 1.5v は同じ向きで 1.5 倍の長さ、−v は反対向き" caption="ベクトルの加算とスカラー倍" align="center" >}}

加算では `a` の終点に `b` の始点を置くと、原点からその終点への矢印が `a + b` になります。スカラー倍では、`1.5v` は `v` と同じ向きで長さが 1.5 倍、`−v` は反対向きで同じ長さです。

特徴量のほか、モデルの重みや[勾配](../partial-derivative-gradient/)もベクトルで表します。ただし、特徴量ごとに単位が違う場合は注意が必要です。例えば、身長を m と cm のどちらで表すかによって、ベクトルの長さや角度も変わります。

### 内積（dot product / inner product）

内積は、対応する成分の積を足したスカラーです。

`a · b = Σ_i a_i b_i`

両方が非零なら、長さ（ノルム）と角度 `θ` を使って `a · b = ||a|| ||b|| cos(θ)` とも書けます。内積が正なら角度は 90° 未満、0 なら 90°、負なら 90° より大きくなります。零ベクトルとの内積も 0 ですが、その場合は角度を定義できません。

```python
a = np.array([4, 1])
unit_a = a / np.linalg.norm(a)
for b in [np.array([3, 2]), np.array([-2, 2])]:
    dot = a @ b
    signed_component = b @ unit_a
    projection = signed_component * unit_a
    print(dot)
```

```text
14
-6
```

{{< figure src="dot_product_projection.svg" alt="上は a = (4, 1) と b = (3, 2) が鋭角をなし内積 14、下は b = (−2, 2) と鈍角をなし内積 −6。緑の矢印は b を a の方向へ射影したベクトルで、下では a と逆向きになる" caption="内積の符号と a の方向への射影" align="center" >}}

緑の矢印は `b` を `a` の張る直線へ射影したベクトルです。`a` の正方向を基準にした符号付き成分は `(a · b)/||a||` で、これに `||a||` を掛けると内積になります。下の図では成分が負です。矢印の長さ自体は負にならないため、内積の計算では射影の長さに加えて、その向きも区別します。

線形回帰の 1 件分の予測は `w · x + b` と書けます。ここで `w` は重み、`x` は特徴量、`b` は切片です。つまり、内積を使って各特徴量に重みを掛けた合計を計算しています。

### 行列積（matrix product）

行列 `A` の形状が `m × k`、`B` が `k × n` なら、積 `AB` は `m × n` になります。結果の `(i, j)` 成分は、`A` の第 `i` 行と `B` の第 `j` 列の内積です。内側の次元 `k` が一致している必要があります。

`(AB)_{ij} = Σ_l A_{il} B_{lj}`

数学上は結合則 `(AB)C = A(BC)` が成り立ちますが、一般には `AB = BA` ではありません。逆順の積が定義できない形状もあります。

<br>

行列積の順序は、変換を適用する順序に対応します。`ABx` は先に `B`、次に `A` を適用します。次の例では、正方形の頂点を列に並べ、伸縮・回転・剪断（せん断）を適用します。

```python
square = np.array([[0, 0], [1, 0], [1, 1], [0, 1], [0, 0]]).T
angle = np.pi / 6
matrices = [
    np.array([[2, 0], [0, 0.5]]),
    np.array([[np.cos(angle), -np.sin(angle)],
              [np.sin(angle), np.cos(angle)]]),
    np.array([[1, 0.6], [0, 1]]),
]
transformed_squares = [A @ square for A in matrices]
```

{{< figure src="matrix_transformations.png" alt="上から伸縮、30 度の回転、剪断を正方形に適用した図。灰色が変換前、赤が変換後で、単位ベクトル (1, 0) と (0, 1) の移り先を青と緑の矢印で示す" caption="行列による伸縮・回転・剪断" align="center" >}}

行列の各列は、単位ベクトル `(1, 0)` と `(0, 1)` が変換後にどこへ移るかを表します。図ではそれを青と緑の矢印で示しています。行列による変換には、これらの例以外に反転や、平面を直線へ潰す射影もあります。すべての変換を逆に戻せるわけではありません。

### データ行列と重みの積

データ行列 `X` に、`n` 件のデータを `n` 行、`d` 個の特徴量を `d` 列で並べます。各行が 1 件、各列が 1 種類の特徴量です。重みを列ベクトルで書くと、

`y_pred = Xw`、形状は `(n × d)(d × 1) = n × 1`

です。各行と `w` の内積が、対応する 1 件の予測になります。以下では計算を見やすくするため切片を省き、学習せずに重みを固定します。

```python
rng = np.random.default_rng(0)
n, d = 8, 3
X = np.round(rng.standard_normal((n, d)) * 1.5, 1)
w = np.array([1.5, -0.5, 0.8])
y_pred = X @ w
print(X.shape, w.shape, y_pred.shape)
print(np.round(y_pred, 2))
```

```text
(8, 3) (3,) (8,)
[ 1.2   1.1   1.42 -2.32 -6.62 -1.65 -0.06  3.9 ]
```

出力の `(3,)` と `(8,)` は、式の `d × 1` と `n × 1` に当たります。NumPy の `w` は一次元配列なので、`@` は `w` を列ベクトルとして掛け、結果も一次元配列で返します。値は同じです。列ベクトルと形状を揃えたい場合は `w.reshape(-1, 1)` を渡すと `(8, 1)` になります。図の shape も NumPy の形状です。

{{< figure src="matrix_regression_layout.png" alt="上から 8 × 3 のデータ行列 X、3 要素の重み w、8 要素の予測 Xw を並べた図。X の各行と w の内積が、Xw の対応する 1 要素になる" caption="データ行列 X と重み w の積" align="center" >}}

1 行目は `[0.2, −0.2, 1.0]` なので、予測は `0.2×1.5 + (−0.2)×(−0.5) + 1.0×0.8 = 1.20` です。観測値 `y` に測定ノイズなどが含まれる場合、予測値 `Xw` との差が生じます。

`X * w` は要素ごとの積で、各特徴量に重みを掛けた値が 3 列のまま残り、形状は `(8, 3)` です。`X @ w` なら Python の行ループを書かずに計算できますが、速度は配列サイズや利用する演算ライブラリなどに依存します。

### ノルム（ベクトルの長さ）

内積で使った `||x||` は L2 ノルム `sqrt(Σ_i x_i²)` です。他に、絶対値の和を取る L1 ノルム `Σ_i |x_i|`、最大の絶対値を取る L∞ ノルム `max_i |x_i|` があります。原点からの長さをノルムで測り、2 点の差 `x − y` のノルムを取ると距離になります。

[正則化](../../ml/regularization/)では、L1 ノルムや L2 ノルムの二乗を重みへの罰則に使います。L1 は一部の重みが 0 になる疎な解を作りやすく、L2 は大きな重みを抑えます。ただし、L2 が各重みを必ず同じ比率で縮めるわけではありません。

### 機械学習での使いどころ

[線形回帰](../../ml/linear-regression/)では `Xw + b` が予測値になり、[ロジスティック回帰](../../ml/logistic-regression/)ではその値をシグモイド関数に通します。ニューラルネットの層では重みを行列 `W` とし、複数の出力を `XW + b` でまとめて計算します。

[PCA](../../ml/pca/) では、中心化したデータを主成分の方向へ射影します。また、非零ベクトル同士のコサイン類似度は、内積を両者の L2 ノルムで割った値です。内積や行列積という共通の演算でも、入力の意味や前処理によって結果の解釈は変わります。

---

### 計算時の注意点

配列の形状だけでなく、各軸がサンプル、特徴量、出力のどれに対応するかも確認する必要があります。行と列を取り違えていても、サイズが合っていれば計算できてしまうからです。大半が 0 の巨大な行列には、[SciPy の疎行列](https://docs.scipy.org/doc/scipy/reference/sparse.html)のような専用の表現が適する場合があります。

線形方程式を解く場合も、式に逆行列が出てくるからといって、そのまま逆行列を計算する必要はありません。数値的に不安定な問題では誤差が大きくなるため、解を求める専用の関数（NumPy の [`np.linalg.solve`](https://numpy.org/doc/stable/reference/generated/numpy.linalg.solve.html) など）や QR 分解・特異値分解を使います。

# ローカル実験

Python 3 と NumPy で動くシミュレーションです。avalanchego は動かさず、ネットワークにも接続しません。

```sh
python3 snow_sim.py
```

`output.txt` は 2026-11-10 に Python 3.14.4、NumPy 2.3.5 で実行した結果です。乱数の seed は試行ごとに 0〜99（実験 5・6 は 0〜19）に固定しているので、同じ版なら同じ数値になります。

- 実験 1: 正しいノードが全員同じ値（blue）を支持している所に、不正なノードが別の値（red）を答え続けます。
- 実験 2・3: 正しいノードが半々に割れた所から始め、不正なノードは問い合わせてきたノードの側の色を答えて、割れたまま確定させようとします。
- 実験 4: α を変えた時の、意見が割れた回数と確定しなかった回数です。
- 実験 5・6: 1 回の決定に使うメッセージの総数を、ノード数を変えて数えます。`pbft_total` は PBFT の通常動作（pre-prepare・prepare・commit）の式で計算した値です。

モデルの単純化（全ノードが同時にラウンドを進める、復元抽出、ステークは全員同じ、メッセージは全て届く、など）は `snow_sim.py` の先頭に書いています。図は 1 つ上のディレクトリの `figures.py` で生成します。

# ローカル実験

Python 3.8 以降の標準ライブラリだけで実行できます。ネットワークにも接続しません。

```sh
python3 sim.py --json
```

- `sim.py`: スレッド 40 本を持つサーバーで、呼び出し先が 10 秒から 40 秒まで応答しなくなる時の動きを 1 ミリ秒刻みで模擬する。条件は Circuit Breaker のノートの lab と同じ
- `output.txt`: Python 3.14 で実行した結果
- `result.json`: `--json` を付けた時に書く、図の元データ（1 秒ごとの値と、上限を変えた時の結果）

到着は乱数の種を 1 に固定したポアソン到着なので、何度実行しても同じ結果になります。
本文の図は、1 つ上のディレクトリの `figures.py` が `result.json` を読んで生成します。

出力の読み方:

- `B ok during outage` は、呼び出し先が止まっている 10〜40 秒に届いた要求 B のうち、処理できた割合です。
- `busy A at 20s` は、20 秒の時点で要求 A が使っていたスレッドの数です。
- 2 つ目の表の `A rejected in normal time` は、停止の前（0〜10 秒）と、停止中の最後の呼び出しが timeout で返った後（42〜60 秒）に届いた A のうち、断られた割合です。

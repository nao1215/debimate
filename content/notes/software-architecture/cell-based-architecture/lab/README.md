# Cell-based Architecture の実験

ポイズンピルを送る 1 人の顧客が、他の顧客をどれだけ巻き込むかを数えます。ワーカー 8 台と顧客 1 万人で、通常の cell（2 台ずつ 4 組）と shuffle sharding（顧客ごとにランダムな 2 台の組）の割り当てを比べ、組み合わせの数から理論値も計算します。

標準ライブラリだけを使い、外部への通信はしません。Python 3.14.4 で実行を確認しました。

```sh
python3 blast_radius.py
```

乱数の種を固定しているので、同じ Python では `output.txt` と同じ結果になります。

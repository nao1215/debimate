# ローカル実験

Python 3.8 以降の標準ライブラリだけで実行できます。ネットワークにも接続しません。

```sh
python3 sim.py
```

- `breaker.py`: 件数ベースのスライディングウィンドウで失敗率を数えるサーキットブレーカー
- `sim.py`: 下流が 10 秒から 40 秒まで応答しなくなる時の呼び出し側を、1 ミリ秒刻みで模擬する
- `output.txt`: Python 3.14 で実行した結果

到着は乱数の種を 1 に固定したポアソン到着なので、何度実行しても同じ結果になります。
本文の図は、1 つ上のディレクトリの `figures.py` が `sim.py` を呼んで生成します。

```sh
uv run --with matplotlib python ../figures.py
```

出力の読み方:

- `fast_fail` はブレーカーに断られて、下流を呼ばずに失敗した要求 A の数です。`Retry(CircuitBreaker)` で `failed=0` なのは、timeout した後のやり直しがブレーカーに断られ、最終結果が `fast_fail` に分類されたからです。
- Retry は単純化しています。試行の間の待ち時間は 0 で、ブレーカーに断られた試行はやり直しません。
- `breaker.py` は状態が変わるたびに `generation` を進め、前の状態で通した呼び出しの遅れた結果を数えません。

Percentage rollout simulation
Python 3 standard library only (hashlib, random). No network is used.
From the repository root:
  python3 content/notes/software-architecture/feature-flag/lab/rollout.py
This is a simulation, not a measurement of any flag management service.
The random seed is fixed (42), so the output is deterministic.
output.txt is the actual output of the command above.
The figure is regenerated with:
  python3 content/notes/software-architecture/feature-flag/figures.py

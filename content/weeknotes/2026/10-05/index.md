#### テトリスゲームをランナーゲームに差し替えて公開

[先週に書いた通り](/weeknotes/2026-09-28/#tetris-クローンを作り出来が良かったので別ゲーに差し替えている)、Tetris クローンとして作っていたゲームをランナーゲームに差し替えて公開した。詳しく見たい方は、後ろに誰も居ないかを確認してから GitHub のリンクを開いて欲しい。リンク先は、女の子だらけだ。女の子がキャッキャしている記事をブログトップに置きたくなかったので、weeknotes 側に記録を残す。

- GitHub: https://github.com/nao1215/rabbitrun
- itch.io: https://nao1215.itch.io/rabbit-run

プレイ動画：  {{< figure src="demo.gif" alt="RABBIT RUN のプレイ画面" >}}

ゲーム性は単純で、矢印キーを使って障害物を避け、遠くまで進めると女の子の画像が貰えるという内容。「単調すぎでは？」と懐疑的になった結果、難易度が上昇し続けた。1マス避けを延々と繰り返すコースをテストプレイしている時に「避けるのに必死で、キャラを見る暇がない」と我に返り、難易度を下げた。ゲームらしさを上げるために、障害物の全破壊、隠しコマンド、隠しキャラ、条件付きクリアボーナスなど、それっぽい要素を導入した。ただし、GitHub で Assets を見れば、報酬の画像を全て確認できる。

今回は、ローカル環境で [ComfyUI](https://github.com/comfy-org/comfyui) を使って素材をどれだけ生成できるかに焦点を当てていた。ゲーム性は二の次であり、女の子で誤魔化した。次回のゲームでは、男性キャラも追加する。以前も書いたが、生成したキャラの顔や服、画風がブレるのだ。厳密に画像チェックする機構を導入したが、画像生成が牛歩だし、妥協が必要だった。434枚のキャラ画像、その他の小物を作るのに一週間かかった。GPU 100%に張り付いた状態で PC が動き続けるので、自室だけ異常に暑い状態になっていた。

今までは、壮大な SLG だったり、ゲームエンジン開発を作って挫折をしてきた。今回、ようやく小さめのゲームを完成させられた。沢山 OSS を開発してきて、開発規模を上手に見積もれるようになった。次回作にご期待ください。生成 AI との親和性を考えると、カードゲームを作る気がする。

#### YAML から漫画を生成ツールをポシャった

ゲーム作りを通して、画像生成の方法が分かり、「これで漫画を書けるのでは？」と閃いた。YAML にコマ割りや効果音、吹き出しが設定できる CLI を Claude に作らせ、5ページほどの漫画を書かせたが、駄目だった。白々しい感じがした。漫画は視線誘導が大事だったり、集中線、墨のような表現など、場面にあった表現を選ばなければならない。例えば、効果音の「ドンッ！」を置くことはできるが、違和感があった。浮いて見える。

あと、GPU が弱いと、トライアンドエラーに時間がかかりすぎる。朝にサーバーを動かして、夜に結果を見て「駄目だねこれは」を繰り返す気力がなかった。素直にポシャった。

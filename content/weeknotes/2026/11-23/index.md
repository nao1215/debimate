#### イトウ製菓が好きかもしれない

息子用に[ビスコ（江崎グリコ）](https://cp.glico.com/bisco/)を買っていたが、大人がつまみ食いするには物足りない問題があった（息子に気づかれると怒られる問題もあるのだが）。子供・大人でお菓子を分け始めると単価が上がる。なるべくお菓子を共有したい。大人がお菓子を食べるなよ、という意見は封殺する。

そこで、ビスコだけではなく、クッキーを常備して誤魔化す方針を採用し始めた。[コンフェッティ](https://www.mr-ito.jp/service/product58.shtml)、[いちごのタルト](https://www.mr-ito.jp/service/product15.shtml)、[アメリカンソフトクッキーマカダミア](https://www.mr-ito.jp/service/product13.shtml)などをお菓子棚に置き始めた。暫くして、どれも[イトウ製菓](https://www.mr-ito.jp/)の商品だと気づいた。他の製品よりわずかに値段が高めだが、味がいい気がする。

{{< figure src="ito-sweets.webp" link="https://www.mr-ito.jp/" alt="イトウ製菓のコンフェッティ ガレットブルトンヌ、いちごのタルト、アメリカンソフトクッキー マカダミアの箱を並べた画像" caption="左から：コンフェッティ（ガレットブルトンヌ）、いちごのタルト、アメリカンソフトクッキー マカダミア<br>出典：[イトウ製菓 公式サイト](https://www.mr-ito.jp/)（2026年11月22日取得）" width="700" align="center" >}}

お菓子と言えば、実家では煎餅・米菓が常備されていたが、最近は全く食べなくなってしまった。嫌いではないのだが、米菓を食べるくらいなら、きな粉ねじり、こんぶ飴、干し芋のような素朴なお菓子が選択肢として強いかもしれない。30代で、この辺りのお菓子を食べる人がいるのだろうか。

#### FIREするにはゲーム販売かOSSか宝くじ

エンジニアは比較的高給取りかつ金融リテラシーがある人が多いので、FIRE（Financial Independence, Retire Early）するケースがある。「テンバガー（株価が10倍以上に上昇すること）を当てました」「1億貯めました」みたいな人が実際にいた。私は FIRE を本気で目指していないが、副収入を増やしたい気持ちが常にある。家電を迷わず買えるぐらいには、金銭的自由が欲しい。デロンギの購入を検討して数年経過している。150億円欲しい。

前提として、私のように一馬力で子供が居ると、正直1000〜2000万を個別株で当てても、仕事を辞めるレベルに達しない。子供の学費が浮いたな、ぐらいの金額だ（いや、当たるなら当たってほしいけどね）。副業で稼ごうにも、AI が万能すぎてフリーランスや業務委託の副業需要が減ってしまった。

そんな状況で大きく稼ぐには、私の場合は以下の3つが考えられる（株は除く）。
- ゲーム販売
- OSS の収益化
- 宝くじで5000万以上の当選

ゲーム販売は、当たれば数百万〜数千万を稼げる可能性がある博打だ。1年以内に1本ぐらい Steam 販売したい。有料販売を試したことがないので、どれぐらい辛い戦いが待っているかを理解できていない。開発が異様に大変なことは、1ヶ月ぐらいの苦行で理解したつもりだ。長きにわたる開発を乗り越え、販売後に無風になるかもしれない。それでもトライしたい。

OSS は、稼げない。ビジネスモデルとして成立しづらい。最初から収益化を考慮しないと、ユーザーは無料版で満足してしまう。スポンサー費は、年間1万にも達しない。私は、OSS を転職が有利になる道具として考えている。OSS 自体で稼ぐのは、無理だ。そもそも、私は趣味で開発しているだけだ。思いついたら、いつの間にかリポジトリができている。

宝くじは、期待値（還元率）が約46%で、公営ギャンブルの中で最も低い。しかも、高額当選に賞金が集中する。宝くじを真剣に計算すると、「機械学習で遊べる競馬の方がマシでは？」と思い始める。競馬は大きく張らないとリターンがないので、私は怖くてできない。人生が大きく変わりそうな5000万円以上の宝くじ当選に焦点を当てると、ロト6・ロト7・BIG・年末ジャンボが候補に挙がる。当選確率を50%に近づけるには、8〜20億円が必要になる。その一方で、定期購入設定して放置できるメリットがある。なお、[下図の宝くじサイトは不正アクセス](https://www.watch.impress.co.jp/docs/news/2156159.html)があったらしい。

色々書いたが、最近は毎週1口のロト6を買い、1回当選する（金額は問わない）まで続ける遊びをしている。当選まで平均で約9ヶ月かかるので、その合間にゲーム開発を頑張るのだ。ここ数日は、開発を止めているが。良いシステムが思いつかないのだ。ストーリーなしでも成立するシステムが好ましい。物語を考え始めると、キャラや設定作りにこだわってしまうが、そこはゲームの本質ではない。ゲーム開発を始めた頃は形にできればポイッとリリースできたが、開発に慣れてしまったら「このクオリティなら、公開する必要はないな」と出し惜しみするようになった。

#### ロト6の確率を体感するためのゲームを公開

{{< figure src="lottery6-ogp.webp" link="https://nao1215.github.io/lottery6/" alt="ロト6と同じ 43 個から 6 個を選ぶ宝くじゲーム lottery6 の OGP 画像" caption="lottery6 の OGP 画像" width="700" align="center" >}}

[nao1215/lottery6](https://github.com/nao1215/lottery6) は、ロト6と同じロジックの宝くじを自動で購入し続けられるゲームだ。[一つ前のトピック](/weeknotes/2026-11-23/c8d6aafd89da/)で宝くじについて言及しており、当選確率を体感するために作った。100万円分買っても、1等はまず当たらない。主人公としてギャルが出てくるが、スターシステムを採用したのでギャルを別ゲームから使い回しているだけだ。正直、ギャルはゲームに不要。

お金が無くなると、男から資金を補充してもらえる。つまり、エンドレスに購入できる。男はデスマーチ（ゲーム）の主人公であり、こちらはまだリリースできていない。1等に当たると一枚絵を表示する仕様だが、どうせ当たらないので手を抜いた。当初は、風呂の中に札束を入れて、ギャルがその中で悪い顔をする予定だった。リリースを優先するために、サボった。当選確率が低いので、誰も画像を正規の方法で拝めないだろう。私は今も1等が出るまでデバッグ用に回し続けているが、何日で終わるだろうか。

#### 芯のある開発者を尊敬している

最近、興味を引かれた OSS は [fkubota/understand-mode](https://github.com/fkubota/understand-mode) だ。understand-mode では、Claude Code の出力から分からない文を選ぶと付箋が生え、本筋の会話を汚さずに質問できる。開発者は前職で1〜2ヶ月ほど一緒だった方だが、殆ど話したことがない。今回の OSS は、偶然目に入った。LLM の出力をキチンと理解しようという姿勢が表れている。私のように OSS を千切っては投げ千切っては投げしている輩とは違う。[Cognitive Debt（認知負債）、Intent Debt（意図負債）](https://speakerdeck.com/twada/debt-metaphor-in-agentic-engineering-age-202609-edition)に対抗するには、良い案だ。直ぐに導入した。

{{< figure src="understand-mode.webp" link="https://github.com/fkubota/understand-mode" alt="understand-mode の画面。Claude の出力の本文から文を選ぶと、横に付箋が生えて質問への回答が表示される" caption="understand-mode のデモ画面。本文の文を選ぶと付箋が生え、その中で Claude が答える<br>出典：[fkubota/understand-mode のデモ](https://github.com/fkubota/understand-mode)（2026年11月26日取得）" width="700" align="center" >}}

私は開発量を増やす立ち回りをしがちなので、認知負債・意図負債を抱えている。しかも、現職で初めて、コードを殆ど自力で読まずに LLM パワーで開発している。前職では自分の脳内にコードマップがあったが、今は殆どない。最後の砦は設計意図や機能に対する理解度だと考えているが、一昔前と比べて記憶に定着していない。その弊害が出ていて、MTG でパッと処理を答えられない。記憶がおぼろげなのだ。ゆっくり開発したいが、手は止められない。

前職の方は、質実剛健で私に強い影響を与える人が多かった。芯がある人が多かった。抽象より具体を重んじたり、オーバーエンジニアリングに苦言を呈したり、異様に開発速度が速かったり……今回の understand-mode も、正面から課題と向き合ってて好感を持った。自分にない発想だった。私は自分自身が大したことない人間だと考えているので、周りの人の良い点を積極的に真似するようにしている。私も誰かに影響を与える立場になる日が来るのだろうか。
